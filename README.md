# 10x AI Growth Marketing Kit

**A growing AI Marketing Skill Kit for everyone who wants to grow with AI.**

**唔係再收集 Prompts，而係將你做 Marketing 嘅判斷，寫成 AI 可以重複執行嘅 Skills。**

好多 Marketer 已經識叫 AI 寫 Post、做 Research、砌 Campaign。

但真正開始工作，就會遇到幾個問題：

- 每次開新對話，都要重新解釋公司、客戶同品牌；
- AI 未做 Research，就已經急住交答案；
- Campaign 睇落好完整，但受眾、Offer、CTA 同 KPI 都係估出嚟；
- 同一段文案改少少，就當成 Threads、LinkedIn、Facebook 同 Instagram；
- Draft 好似寫完，但冇人知道根據乜嘢驗收，亦唔知下一步交俾邊個。

所以我整咗呢套 **10x AI Growth Marketing Kit**。

目前先由四個可以安裝、閱讀、測試同修改嘅 AI Marketing Skills 開始，將內容研究、Full Funnel 策劃、SEO／GEO 內容同社交文案，串成一條有來源、有判斷、有交接、有 Human Review 嘅工作流。

四個 Skills 只係起點。我哋會按照真實 Marketing 工作持續測試、改善同加入更多 Skills，令呢個 Kit 同每一個想用 AI 成長嘅人一齊成長。

> **目前版本：** `v0.1-team-test`
>
> **目前可用：** 4 個完整 Skills
>
> **發展方向：** [10-Skill Roadmap](10-SKILL-INTRO-AND-FLOW.md)
>
> **適合對象：** 所有想用 AI 推動內容、品牌、Campaign、團隊或生意增長嘅人；方法源自 Jimmy 同香港市場嘅實戰

## 我點解會寫呢套 Skills？

我一路由 Designer、Marketer、Growth Marketer，做到而家嘅 AI Growth Builder。

實際做 Marketing 時，我發現 AI 最容易令人誤會嘅地方，唔係佢「唔識做」，而係佢太快交到一份睇落似完成嘅答案。

一份文案可以句句通順，但冇真正觀點；一份 Campaign Plan 可以有晒 Funnel、Channel 同 KPI，但入面一半資料從來冇人確認；一篇 SEO 文章可以有齊關鍵字，但冇一個重要 Claim 有可靠來源。

問題通常唔係欠一條更長嘅 Prompt。

問題係我哋未將自己平時做決定嘅方法講清楚：

- 開始之前要睇乜；
- 資料不足時應該問乜；
- 邊啲係事實，邊啲只係判斷；
- 工作應該按照甚麼次序進行；
- 交付要包含甚麼；
- 去到邊一步一定要人拍板。

我寫 Skill，就係想將呢啲平時收埋喺腦入面嘅工作判斷，變成團隊同 AI 都可以理解、重複同改善嘅方法。

> AI 工具可能幾個月就轉一次，但你點樣 Research、判斷、交接同驗收，先係真正可以累積嘅能力。

## Skill 唔係一條「超級 Prompt」

一條 Prompt 通常只係話俾 AI 知「今次想做乜」。

一個 Skill 就係將「呢類工作應該點樣做」寫成一套可重複使用嘅工作方法。

| 一般 Prompt | 一個完整 Skill |
| --- | --- |
| 一次性指令 | 可以重複安裝及使用 |
| 依賴今次對話有冇講清楚 | 先檢查需要嘅 Context |
| AI 可以直接估缺失資料 | 清楚標示已知、假設及缺口 |
| 每次輸出格式都可能唔同 | 有固定 Output Contract |
| 好難交俾另一個人繼續 | 有明確 Handoff |
| 覺得「寫得幾好」就算完成 | 有 Quality Gate 同測試準則 |

一個實用 Skill，通常至少包含：

1. **Trigger**：甚麼情況應該啟動；
2. **Required Context**：開始前需要讀取甚麼；
3. **Questions**：缺少關鍵資料時點樣問；
4. **Workflow**：工作次序；
5. **Output Contract**：交付格式；
6. **Guardrails**：不可以越過嘅界線；
7. **Quality Gate**：完成前點樣驗收；
8. **Handoff**：下一步交俾邊個 Skill 或人。

---

## 點解一個 Skill 要有咁多規限？

因為 AI 最危險嘅唔一定係完全答錯，而係用好多合理文字，將未確認嘅嘢包裝成好似已經決定。

| Skill 入面嘅規限 | 實際解決嘅問題 |
| --- | --- |
| Trigger | 防止用錯 Skill 處理任務 |
| Required Context | 防止未了解公司就開始生成 |
| Status | 分開已確認、假設、缺口及阻塞 |
| Questions | 補回真正影響結果嘅資料 |
| Workflow | 保留正確思考及執行次序 |
| Output Contract | 令結果可以直接驗收及交接 |
| Guardrails | 防止虛構、越權或未批准發布 |
| Quality Gate | 定義甚麼先叫真正完成 |
| Evals／Test Cases | 檢查修改 Skill 後有冇整壞原有行為 |

> 規限唔係為咗限制創意，而係令創意可以被驗收、重複同交接。

## 呢套 Kit 背後嘅工作方法

我將 Marketing 工作拆成五層：

```text
Company Context
      ↓
Research Evidence
      ↓
Strategic Decision
      ↓
Content Production
      ↓
Human Review
```

核心原則係：

### 1. Context before creation

未了解公司、客戶、Offer 同目標之前，唔應該急住生成內容。

### 2. Evidence before opinion

先讀真正 Sources、客戶語言同市場訊號，再決定我哋有甚麼值得講。

### 3. Strategy before production

唔係一開始就問「出咩 Post」，而係先確認想改變邊一類受眾、推動甚麼行動，同內容位於 Funnel 邊一層。

### 4. Human judgment before publishing

AI 可以研究、整理、挑戰、建議同起 Draft；事實、品牌立場、客戶資料、預算及正式發布，仍然要由人審批。

## 目前四個 Skills

### 1. Social Content Research／社交內容研究

`預計 10–30 分鐘`

👤 **你只需要提供：** YouTube、Instagram、Facebook、Threads、LinkedIn、X 連結，或者影片、截圖、Caption、逐字稿。

#### 點解我會寫呢個 Skill？

做 Content 最常見嘅錯誤，唔係冇 Idea，而係太早開始寫。

我哋見到一條熱門內容，好容易直接叫 AI「幫我整三條類似嘅」。但如果 AI 根本睇唔到 Carousel 圖片、只讀到搜尋摘要，或者將創作者觀點當成已核實事實，最後只會變成憑印象抄橋。

呢個 Skill 第一件事唔係分析，而係交代自己實際讀到幾多：

- `FULL`：正文及主要媒體已讀；
- `PARTIAL`：只讀到部分內容；
- `IMAGE_ONLY`：只有圖片或截圖；
- `BLOCKED`：內容無法存取。

#### 工作流程

```text
提供內容
→ 確認讀取範圍
→ 提取實際證據
→ 分開 Evidence 與 Interpretation
→ 分析 Hook、結構、Proof 同 CTA
→ 檢查風險
→ 發展原創 Content Angles
```

讀取方法可以包括瀏覽器、官方字幕、逐字稿、OCR；影片冇字幕時，先考慮用 Whisper 轉錄，FFmpeg 可以協助抽音訊或整理媒體。呢啲只係取證方法，唔代表每一個平台、私人內容或受限制影片都一定讀得到。

#### 主要輸出

- Access state；
- 實際讀到嘅內容；
- 一句總結；
- Hook 與結構分析；
- 值得參考嘅機制；
- 風險或盲點；
- 三個重新發展嘅原創角度。

➡️ [打開 Social Content Research Skill](skills/social-content-research/)

### 2. Full Funnel Campaign Planner／完整漏斗企劃

`預計 30–60 分鐘`

👤 **你只需要提供：** 產品、課程、活動或服務資料，以及現有受眾、渠道、團隊、期限、預算或過往 Campaign 資料。

#### 點解我會寫呢個 Skill？

Campaign 唔係一張「今個月出咩 Content」嘅表。

一個 Campaign 要由同一個 Business Outcome 出發，連接 Audience、Offer、Core Message、Proof、Funnel Stage、Asset、CTA、Owner 同 Success Signal。

當關鍵資料未清楚，呢個 Skill 唔會用假設填滿成份 Plan，而係進入 **Grill Me**：

1. 一次只問一個真正影響策略嘅問題；
2. 解釋點解需要決定；
3. 提供 2–3 個可行選項；
4. 提出一個建議及原因；
5. 等你回答，再進入下一題。

#### 工作流程

```text
讀取現況
→ 標示 CONFIRMED／ASSUMED／OPEN／BLOCKED
→ Grill Me
→ 鎖定 Outcome、Audience、Message 同 CTA
→ 建立 Full Funnel
→ 排列 90 日優先次序
→ 輸出 Specialist Handoffs
```

Funnel 可以包含：

```text
Discover → Engage／Capture → Nurture → Convert → Retain → Refer
```

唔係每個 Campaign 都需要全部 Stage。不需要嘅部分應該明確標示 `NOT REQUIRED`，而唔係為咗睇落完整而硬加。

#### 主要輸出

- Campaign Summary；
- Current State；
- Full Funnel Map；
- 90-Day Priorities；
- Content and Skill Handoffs；
- Measurement、Risks and Approval。

➡️ [打開 Full Funnel Campaign Planner Skill](skills/full-funnel-campaign-planner/)

### 3. SEO + GEO Content／搜尋及 AI 引用內容

`預計 45–90 分鐘`

👤 **你只需要提供：** 題目或搜尋問題、目標客戶、地區、內容目標、可用來源、公司資料及 CTA。

#### 點解我會寫呢個 Skill？

SEO／GEO 唔應該由「幫我加多啲 Keywords」開始。

應該先理解搜尋者真正想了解、比較、解決定購買甚麼，再判斷公司有冇足夠資料同資格回答。

呢個 Skill 會將重要 Claim 分成：

- `VERIFIED`：已有可靠來源核實；
- `PROVIDED`：由用戶提供但未獨立核實；
- `INFERENCE`：根據證據作出嘅判斷；
- `SOURCE NEEDED`：未補來源前不可當成公開事實。

#### 工作流程

```text
確認 Search Intent
→ 選擇 Content Type
→ 研究 Sources
→ 建立 Source and Claim Map
→ 設計文章結構
→ 撰寫 Draft
→ SEO／GEO／Citation QA
→ Human Review
```

SEO 同 GEO 共用同一個底層：內容要準確、具體、有來源、結構清楚，而且真係幫讀者完成一個決定。唔會為咗迎合演算法而大量堆砌 FAQ、短答案或者 Keywords。

#### 主要輸出

- Search Intent Brief；
- Source and Claim Notes；
- Outline；
- Article Draft；
- Meta Title and Description；
- Suggested Internal Links；
- QA Status and Open Items。

➡️ [打開 SEO + GEO Content Skill](skills/seo-geo-content/)

### 4. Social Post Writing／平台原生社交文案

`預計 10–20 分鐘`

👤 **你只需要提供：** 一個已核實 Source、Idea、Campaign Handoff 或觀點，再加 Audience、Voice、平台同 CTA。

#### 點解我會寫呢個 Skill？

同一個 Insight 可以去唔同平台，但唔應該將同一段文字 Copy and Paste 四次。

Threads、LinkedIn、Facebook 同 Instagram 嘅閱讀情境、節奏、Context 同 CTA 都唔同。真正應該保留嘅係同一個核心觀點，而唔係同一個句式。

呢個 Skill 使用一個簡單原則：

> **One Post, One Job, One Point.**

每篇 Post 先揀一個主要工作：

- Teach；
- Build trust；
- Start conversation；
- Announce；
- Drive action。

#### 工作流程

```text
讀取可靠內容
→ 選擇 Audience 同 Voice
→ 鎖定 One Job、One Point
→ 選擇內容 Shape
→ 撰寫 Source Version
→ 按平台重新設計 Hook、節奏同 CTA
→ Fact／Voice／Platform QA
→ 輸出 Draft Pack
```

Founder、Company 同 Neutral Expert Voice 亦會分開處理。AI 不可以為咗增加故事感，代你虛構失敗、客戶、對話或個人經歷。

#### 主要輸出

- Decision Header；
- Threads Draft；
- LinkedIn Draft；
- Facebook Draft；
- Instagram Caption Draft；
- CTA options；
- Assumptions and source notes；
- Status: `DRAFT`。

## 四個 Skills 點樣一齊工作？

```text
來源／社交內容
      ↓
social-content-research
      ↓
full-funnel-campaign-planner
      ├── seo-geo-content
      └── social-post-writing
      ↓
Human Review
```

每個 Skill 都可以獨立使用。但當上一個 Skill 交出可靠資料，下一個 Skill 就唔需要由零開始估。

### 一個香港 SME 示範情境

以下只係教學流程，唔係真實客戶成效：

假設一間香港中小企準備推出「AI 工作流程培訓」。

1. 用 `social-content-research` 研究市場上相關影片、貼文同客戶討論，分開證據、觀點同可發展角度；
2. 用 `full-funnel-campaign-planner` 確認主要受眾、Offer、核心訊息、CTA、渠道同轉化路徑；
3. 將需要建立搜尋信任嘅題目交俾 `seo-geo-content`；
4. 將 Campaign 觀點同活動訊息交俾 `social-post-writing`，分別製作平台原生 Draft；
5. 由負責人核實 Claims、品牌語氣、活動資料同 CTA，再決定發布。

真正嘅價值唔係「一次過生成好多 Content」，而係每一步都知道資料從邊度嚟、點解咁決定、下一步交俾邊個。

## 唔好只學識「用」Skill

我想用呢個 Repository 教嘅，唔係叫大家複製 Jimmy 嘅答案。

真正目標係學識將自己做事嘅判斷寫成 Skill。

你可以用以下練習：

1. 揀一個真實 Marketing 任務；
2. 用原版 Skill 跑一次；
3. 找出一個唔符合你公司做法嘅結果；
4. 打開 `SKILL.md`、`references/` 或 `assets/`，找出控制呢個結果嘅規則；
5. 每次只修改一項；
6. 用同一個任務再跑一次，比較 Before／After。

你要問嘅唔係：

> 「點樣令 AI 寫得再靚啲？」

而係：

> 「我自己平時根據甚麼資料作判斷？邊個步驟唔可以跳過？甚麼結果先算合格？」

當你答到呢三條問題，就已經開始由 AI User 變成 AI Builder。

## 安全及 Human Review 界線

呢套 Skills 會保留以下共通原則：

- 資料不足時標示缺口，不虛構公司、客戶、合作、價格、數字、結果或個人經歷；
- `Draft` 不等於 `Approved`；
- `Approved` 不等於 `Published`；
- 不會自動發佈、發送訊息、花廣告預算或處理客戶個人資料；
- 涉及時效性資料、法規、產品功能、外部 Claim 或第三方內容時，需要核實當前來源；
- AI 可以提出建議，但品牌立場、公開承諾、客戶資料及最終發布由人負責。

- `references/`：需要時先讀取嘅詳細框架；
- `assets/`：可以直接使用嘅 Brief、Checklist 或 Output Template。

第一版刻意冇加入自動 Scraping、Database、API Publishing 或大量不必要 Scripts。Folder 多唔代表 Skill 好；每個 File 都應該有清楚責任。
