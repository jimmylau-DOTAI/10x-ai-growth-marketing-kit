# Blog Banner

沿用現有文章／brief，抽一個主題與短副標；不要塞入全套 Carousel 文案或加無來源 claim。只做 Banner 不必重寫文章。

按網站用途與已確認尺寸重新安排橫向字圖關係；保留 Style 嘅標題處理、主角份量、質感與視覺層次。當次構圖記 job，唔另生 Style DESIGN，唔拉伸方圖。

只在用戶要求先比較方向時，交指定數量嘅標題／構圖方向，等該 Banner 選定；普通單圖或已有選擇就接續。IG 方向批准不自動代替 Banner 選擇。

用戶要求完整品牌圖時，完成可見文案與真 Logo；同時交有意義檔名與描述實際內容嘅 alt text。圖做完不等於 CMS 已上架或 SEO 排名有保證。
