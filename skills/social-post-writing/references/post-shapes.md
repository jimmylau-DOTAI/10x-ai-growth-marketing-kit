# Post Shapes

## Teach

用於解釋方法、流程或錯誤。

```text
Hook → Problem → Better method → Example → Next step
```

成功標準：讀者可以講出或應用一個具體方法。

## Opinion

用於提出清楚判斷。

```text
Claim → Common belief → Reasoning → Evidence or implication → Invitation
```

成功標準：觀點有理由，不只係反對主流。

## Story

用於真實經歷、觀察或轉變。

```text
Moment → Tension → Decision → Result → Lesson
```

成功標準：細節來自真實資料。沒有親身材料時改用 Case、Observation 或 Teach。

## Announcement

用於活動、合作、產品或里程碑。

```text
What changed → Who it helps → What is included → Why it matters → Next step
```

成功標準：不是先寫長篇多謝或公司自我介紹。

## Conversion

用於推動報名、下載、查詢或購買。

```text
Problem / desired result → Offer → Proof → Friction reducer → CTA
```

成功標準：Offer、資格、期限及 CTA 已確認；沒有虛構稀缺性。

## Shape selection

| Primary job | Default shape |
| --- | --- |
| Teach | Teach |
| Build trust | Story、Case 或 Teach |
| Start conversation | Opinion |
| Announce | Announcement |
| Drive action | Conversion |
