# Social Post Quality Gate

## Strategy

- [ ] Audience 清楚
- [ ] Post Job 只有一個
- [ ] One Point 可以用一句表達
- [ ] Shape 符合 Job

## Evidence

- [ ] 來源或 Campaign Handoff 已讀
- [ ] 人名、公司、日期、數字、產品及合作已核實
- [ ] 沒有虛構第一身故事、客戶說話或結果
- [ ] Observation、Inference 及 Fact 有適當語氣區分

## Writing

- [ ] Hook 服務讀者，而非公司自我介紹
- [ ] 內容有具體例子、流程、Proof 或判斷
- [ ] 沒有空泛詞：革命性、顛覆性、最強、一鍵、完美
- [ ] 沒有資訊表、會議紀錄或工具 Feature Dump 感
- [ ] Emoji、Hashtag 及換行有目的

## Platform

- [ ] Threads、LinkedIn、Facebook、Instagram 版本有實質差異
- [ ] LinkedIn 不過度碎句
- [ ] Facebook 有需要時用清楚連結 CTA
- [ ] Instagram Keyword CTA 只在機制存在時使用

## Delivery

- [ ] CTA 為 CONFIRMED、OPEN 或 NOT REQUIRED
- [ ] Assumptions 已列出
- [ ] Status 為 DRAFT 或 READY FOR REVIEW
- [ ] `OPEN`、Assumptions、Source Notes 及 Status 沒有出現在公開 Post Body
- [ ] 沒有聲稱已發佈
