# Image acquisition

用於下載指定帖文嘅單圖、輪播或相簿。先核對原帖連結、作者或貼文 ID，然後由有權開啟嘅原頁操作。只下載時交圖片檔同張數，整理風格或分析由下一步做。

## Instagram 輪播

1. 只喺指定貼文嘅媒體區／當前輪播頁揀真正展示緊嘅內容圖，排除頭像、縮圖、預載但未展示嘅 slide 同推薦帖。未撳下一張之前先讀第一張。等圖實際載入（例如 `img.complete && img.naturalWidth > 0`），由已核對嘅 `img` 讀 `img.currentSrc || img.src`。記低原帖、輪播位置（有就記）、目前圖片同完整 URL。單圖做到呢步即可。
2. 用原帖嘅下一張／右箭嘴，每次前進一張。等當前 slide 標記或位置改變、新圖載入先讀。將每張新圖追加到同一清單，之前嘅紀錄保留。DOM 可能只保留當前幾張；到最後先掃一次會漏。混合圖／影片帖按原位置記錄，影片項按 [video-acquisition.md](video-acquisition.md) 獨立處理。
3. 由封面做到最後一張。按目前位置核對次序，有平台實際提供嘅穩定 media ID 就用 ID 辨認同一檔案，並保留刻意重複嘅輪播位置。無 ID 用位置及下載後內容 hash 對證。相同圖片有多條不同裁切／尺寸／簽名 URL，唔應重算同一個位置。交件按 `01`、`02`、`03` 排，核對原帖顯示嘅總數或末頁證據；任何未取到嘅位置列缺項。

## 保存圖片網址並下載

- 直接用頁面已載入嘅 HTTPS 圖片 URL，例如 IG／Facebook 可能見到嘅 `scontent...`。簽名連結要逐字照用，包括 `?` 後全部參數及原有編碼。唔好刪減、解碼再編碼、重排參數或手動改尺寸。分開以照片 ID／位置做去重，實際下載仍用完整連結。呢個係頁面實際載入嘅尺寸；原帖有更高解像度嘅正式檢視就由嗰度取。
- 連結過期或回 `URL signature mismatch` 時，由原頁重新開該張圖、重讀完整 URL 再試一次。仍然因登入、權限、頻率限制等無法取得就停喺該項。能正常開圖但取唔到直接檔案，可用原生下載／匯出或擷取可見媒體，將截圖獨立標明。只喺當次下載使用簽名 URL，交件與紀錄留原帖連結同實際檔案。
- 檢查回應係成功、真圖片可解碼同尺寸合理，避免將登入頁、錯誤頁或縮圖當圖片。逐張交可開檔，同時標明取得幾多張、下載或截圖、欠缺位置。只見封面或未證實到尾時，完整性列為部分；有 8 個已確認位置就核對 8 個，包含原帖刻意重複嘅位置。

## Facebook 同其他平台

| 平台／介面 | 做法 |
| --- | --- |
| Facebook 相簿／多圖帖 | 由該帖打開相片檢視器，對照帖文或相簿身份，逐張前進同記錄當前相片。停止於同一帖／相簿嘅尾張，排走 viewer 跳入其他相簿、推薦帖或留言附件嘅圖片。相片檢視器有原生下載就可用。 |
| 其他公開圖片輪播／相簿 | 確認該平台確實有可見媒體或原生下載。瀏覽器展示普通 `img` 時，可沿用「先讀當前圖 → 前進一張 → 追加 → 對尾張」；例如現有已授權渠道已回傳完整媒體清單，可按來源次序逐張取得，毋須重覆點擊。 |
| Canvas、CSS 背景、影片、受限頁面 | 如果媒體唔係普通 `img`，揀平台提供嘅可用下載／匯出或其實際媒體方法；影片用獨立流程。只可取得可見畫面時標截圖；登入、受限或無法核對來源就列未取得。 |
