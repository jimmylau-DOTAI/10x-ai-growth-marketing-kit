# Grill Me Intake

## Rule

一次只解決一個會改變策略嘅決定。先讀現有資料；已知答案直接記錄，不再詢問。

## Decision order

1. Business Outcome
2. Primary Audience
3. Audience Awareness
4. Offer
5. Core Problem
6. One Core Message
7. Proof
8. Main CTA
9. Team、Budget、Timeline
10. Success Signal and Stop Rule

不需要固定問足十題。只有關鍵缺口先問。

## Question format

```markdown
## 今次只需要決定一樣嘢

**問題：**

**點解重要：**

**選項：**
1.
2.
3.

**我嘅建議：**

**會影響：**

請先揀一個；確認後我再處理下一個缺口。
```

## Good question

```text
今次 Campaign 最主要係收集合資格查詢，定直接賣課程？

建議先用「合資格查詢」，因為你未有已確認價格及成交基準。
呢個答案會改變 Landing Page CTA、跟進流程同成功指標。
```

## Stop conditions

- Outcome、Audience 或 Offer 缺失：不可輸出完整 Funnel；
- Proof 缺失：可以規劃，但把 Claim 標為 `OPEN`；
- Budget 未定：提供決策框架，不提供看似精準嘅媒體預算；
- Benchmark 未提供：把 KPI 標為 `TEST TARGET`，不得扮成行業事實。
