# AI 剪片＋特效製作

新片由揀方向開始。真人原聲先確認可播 First Cut，素材或畫外音片先確認粗排。第一鏡試字幕擺位同特效，揀定先延伸其他分鏡。局部修訂由受影響嘅地方接住做。

## Agent 開工

- 呢套 Skill 可以連同 `references/` 一齊交畀 Grok Bot 或其他可操作檔案嘅 Agent。先讀本檔，再按工作讀 [工具、名詞同執行檢查](references/runtime-and-terms.md) 同 [FFmpeg 剪輯命令](references/aroll-and-effects.md#本機命令起點)。用戶交原片同講成品目標就可以開始；工具、參數同切點由 Agent 預先核對。
- **FFprobe** 讀原片規格，**FFmpeg** 分析、剪接同輸出。**A-Roll** 係主口播，**B-Roll** 係補畫面，**First Cut** 係可播粗剪。先用偵測搵候選，再聽原聲及睇畫格決定剪邊度。
- 進入已確認方向嘅實作時，先驗證現時環境跑到 `ffmpeg`、`ffprobe`，讀到原片及寫得到輸出。Grok Bot 若要交由可執行命令嘅 Cloud Agent，沿用已授權工作區，核對該 Agent 實際讀到素材。無可用執行環境時，可先交剪接表或待核對位置，清楚交代輸出狀態。

## 0. 交十個方向，等用戶揀定

- 先睇用戶提供嘅素材、成片目標同指定產品來源。產品未核實時，只用畫面構思並標出要核對嘅資料；讀唔到指定來源，就交代缺口，產品資料等用戶補返。
- 方向未定時，交一張 **10 行**比較表，欄位係 **編號 01–10｜Hook｜內容主軸｜銷售方向**。每行一套互相配合嘅方案。Hook 提供頭一兩秒實際可講或可出嘅短句；內容主軸寫清觀眾接住會睇到乜；銷售方向交代打動邊類人、用咩理由推動下一步。非銷售片將最後一欄用於觀眾下一步。
- 十個 Hook 要用唔同嘅開場吸引力。逐行核對主軸同購買理由有實質分別，並用現有畫面同已核實資料支持。CTA 可以沿用用戶指定嘅同一句。表後推薦一行，講一句原因，再請用戶揀編號或講清想合併嘅方向。
- **等待明確選擇。** 交表後停喺方向。用戶選定一個編號、明確接受推薦，或者確認合併方案後，先寫完整劇本、分鏡或派工剪 First Cut。只叫「開始」或只提供素材仍屬待揀。已明確指定方向嘅工作或沿用已確認方向嘅局部修訂，直接接續該階段。

## 1. 按已確認方向交 First Cut 或粗排

- 有現成稿先核對；未有稿先寫可照讀嘅短稿。確認片長、觀眾、一個主要訊息同需要嘅 CTA。核對產品、示範及數字是否有素材支持。未試讀嘅時間用估計值。
- **有真人原聲。** 用 FFprobe 讀取片長同音軌，再用 FFmpeg 找停頓、黑畫面同突變位置。以原聲、逐字稿同切點前後畫格判斷保留或刪除，主動剪走失敗起句、重錄、冗長停頓同重複鏡頭，保留自然語氣。按 [FFmpeg First Cut 方法](references/aroll-and-effects.md#用-ffmpeg-剪-first-cut) 輸出一條可播放 A-Roll MP4，同時記錄原片時間、剪後時間同重要刪剪原因。
- **以素材或畫外音主導。** 用實際素材同試讀定節奏。先交開場用邊段原片、全片粗略順序同每段用途。有得剪就交一條可播粗排。其他分鏡嘅字幕位置、動效同逐鏡圖，等第一鏡獲確認先展開。
- 如有參考片，用 `rea-video` 翻指定段落或關鍵幀，只記會用到嘅做法同畫面證據。要提煉長期風格時可用 `image-style-lab`。參考提供表達方法，內容說法由今次素材核對。
- **確認節奏。** 有真人原聲先俾用戶播 First Cut，確認講嘢次序、節奏同切點。素材或畫外音片確認粗排同開場用邊段原片。之後只試第一鏡。

## 2. 第一鏡先定字幕擺位同特效

- 用同一段第一鏡、同一句已確認文字、同一聲軌同三款一致嘅片長，做 A／B／C。每款各有唔同嘅字幕位置或字級主次，配一個有用途嘅動作。睇 [第一鏡三款點試](references/aroll-and-effects.md#第一鏡三款點試) 揀做法。
- 交三段手機比例可播試片，俾用戶比較字幕入場、停留時讀唔讀得完，同動效帶視線去邊。有需要就把音效對落實際動作。環境只做到靜態時，交標明起點同落位嘅畫格，列明動效／聲效待試。
- **等用戶確認第一鏡。** 記低所選款：字幕區及避位、字級比重及字效、重點字、動效入／停／收同音效 cue 如適用。揀定先做其餘分鏡。用戶已確認一套樣式嘅局部修訂可以沿用。

## 3. 延伸其他分鏡，對口播、字幕同動效

- 沿用第一鏡揀定嘅字、層級同動效用法。其餘鏡頭按主體同語意避位，畫面夠清楚可以只留字幕。先用已確認嘅樣式交完整分鏡表：**成片時間｜來源時間｜口播／字幕｜主體動作｜SFX cue**。遇到遮住主體或平台介面，先按同一套規則調字幕位置。
- 沿用確認過嘅原聲。要新配廣東話時，建議 **ElevenLabs**，揀當時支援 Cantonese 嘅模型及獲授權聲線。先試一句有品牌名或粵語重點字嘅台詞，核對讀音、語速、語氣，之後可逐句做，方便局部重配。
- 要做字幕時，跟 [抽字幕、轉錄廣東話同輸出 SRT](references/subtitles.md) 嘅命令。有可用文字字幕軌就用 FFmpeg 抽取，按剪接表換算；其餘用 Whisper `yue` 轉錄剪後原聲。按目前時間線聽校再交 UTF-8 SRT。
- 按實際聲音重對 **成片時間｜來源時間｜口播／字幕｜主體動作｜SFX cue**。字幕按已錄到嘅原話和語意斷句。推近、出字同 SFX 要同步就共用 cue；換聲或改剪點時重對受影響段落。

## 4. 加底樂，完成預覽或成片方案

- 畫面、口播同 SFX 對好後先鋪底樂。有講嘢時降低底樂，重點位先留空間俾音效。語音、SFX 同底樂分軌。整到成片方案就交時間線、素材位置、特效／聲音落點、輸出設定及待補項。
- 需要實作時，新片優先用 Remotion，已有可用原稿就沿用相應引擎。Remotion 用獨立鏡頭元件、`Sequence` 同 `useCurrentFrame()`，字型載入完成先出畫。新模板先試一個代表段連聲輸出；合片由同一主時間線統一。

## 5. 審實際輸出

要求成片時，按手機畫幅抽查所有鏡頭同切點。特別檢查開頭三秒有冇清楚主體、關鍵動作前後有冇跳黑／空格、字幕有冇遮關鍵畫面、尾段讀唔讀得完。直接用最終 MP4 檢查配聲、音效、尺寸、幀率、時長同完整解碼；口播或數字有疑問就從最終 MP4 抽音聽校，需要時輔以轉錄對稿。返工記 **時間點｜看到／聽到嘅問題｜具體改法**，按受影響範圍重驗。交成片與可重開嘅原稿；實際做到邊一步就按邊一步交代。
