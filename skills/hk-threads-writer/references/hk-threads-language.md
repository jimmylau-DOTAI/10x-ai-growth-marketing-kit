# Hong Kong Threads language

目標係香港人喺手機自然會讀落去嘅文字。唔係將書面中文逐粒字換成廣東話，亦唔係塞滿語氣詞扮地道。

## Brand and copy-style context

寫作／改稿前先做，同一 owner 讀現有資料即可，毋須另裝或轉交其他 Skill。

首次建立或要求保存時，依 [tone-learning.md](tone-learning.md) 完成試稿、確認及原 TONE 更新。已有檔案仍為 TBC 時，先建立可供學生判斷的稿，唔只聲稱 neutral fallback 就略過身份思考。

- 當次指定的作者／品牌、語氣及風格優先。先由目前 Project 的 `Threads/TONE.md` 與其已指向樣本定位適用文字風格，再讀該 Project 的品牌資料；平台共用 TONE 不帶品牌身份，另一個 Project 的 TONE／sample 不可作 fallback。Standalone 使用亦先找當前 Project 的品牌／風格入口，唔因沒有 Vault 就忽略可讀資料。不依賴固定私人路徑，不掃全庫或跨到未獲授權資料。
- 品牌聲音決定誰在說話、讀者關係、親切或正式程度及慣用字眼；文字風格決定 Hook、敘事、句長、留白、符號及收尾。視覺 STYLE／DESIGN 不自動等於文案規則。
- 說話關係要在正文成立：作者是同行者、顧問、產品團隊或其他角色，按真正資料決定，不能只改稱呼。讀者須連當次處境一起定位；不預設對方無知、心急或做錯。身份可以從態度與敘述呈現，不必每篇自我介紹；「我哋」亦不能暗示未有證據的共同經歷。
- 選最多一個適用 named copy Style，必要時讀一篇對應樣本。看正文與適用範圍，唔只看檔名；空白模板或 TBC 不算已取得風格。已在本輪讀過且未變的資料可沿用。
- 先回看當次對話已提供的樣本、被接受／退回的具體寫法，再沿已指向的 Project 路徑取回需要的稿。正式 TONE 空白時，可把這些當本次候選參考，不能自行升級成已批准品牌規則；唔因沒登記就漏掉可用 context。
- 對照參考的具體句段：如何入話題、解釋看法、接續上一句、稱呼讀者、落重點及收尾。選本稿需要的特徵即可；只抽出「親切、短句」不足以指導寫作。多版本可借同一參考的不同機制，不必混入多套品牌聲音。
- 提取本稿需要的特徵作寫作與驗收依據，唔照抄樣本文字、外部身份、第一身經驗或商業承諾。跨品牌參考只借適用機制，不能蓋過本品牌聲音；若只有其他平台樣本，標明有限轉用，不當成 Threads 已確認 Style。
- 當次要求優先；精確且適用的 Threads 規則決定平台表達，共通品牌底線仍保留。資料矛盾到影響作者身份或意思時，只澄清該衝突，唔重問已清楚選擇。
- 確實找不到可用風格時，用現有品牌資料配中性香港口語繼續 draft，簡述缺口；無品牌資料亦唔發明人設。部分資料可用標 partial_pending_review，全無可用聲音標 neutral_fallback；只有缺少指定參考令任務無法成立才問必要問題。
- receipt 留實讀的 brand_voice_source、copy_style_source、稿件可見的 style_application 及 style_status；聲稱讀過不等於有執行證據，需能對返實際讀取與成品。Brand-neutral 係套件不內置私人聲音，唔係禁止使用當次品牌資料。

## Default register

- 香港社交文案預設用自然廣東話、繁體字。
- 同一篇保持一個穩定 register：朋友式、專業口語、第一身紀錄或評論式，唔好中途變客服稿。
- 已選品牌／作者聲音優先於本節一般寫法；缺資料的處理見上方 Brand and copy-style context。
- 專有名詞、產品名、介面文字同常用術語可以保留 English，唔使勉強翻譯。

## Local wording

用香港人真正常用而又配合情境嘅詞，例如：

- 「而家、之後、搵、睇、撳、開、做緊、搞清楚、卡住、落手」；
- 「價錢、連結、設定、檔案、資料夾、版本、做法」；
- 「其實、最麻煩係、講到底、我會咁揀」只喺真係有語意功能時用。

唔好為咗顯得香港而密集加入「啦、喎、啫、㗎、囉」。短段通常零至一個語氣詞已經夠；專業內容可以完全唔用。

## Chinese and English mixing

- 香港讀者慣用嘅 product、workflow、prompt、Hook、CTA、link、draft 可以保留。
- 一個概念揀定中文或 English 後保持一致，唔好輪流換同義詞扮豐富。
- English 唔應該用嚟掩飾空泛：講 `workflow` 就要交代邊一步接邊一步。
- 產品功能、按鈕名同方案名要跟 source 原文，唔好自行本地化。

## Sentence rhythm

- 先講人做緊咩、卡喺邊、見到咩，再講抽象結論。
- 必要脈絡可以用長句；立場、轉折、判斷用短句落地。
- Fragment 只留畀 Hook、pivot 或 punchline，例如「真正麻煩嘅係：」；正文唔好全部變殘句。
- 一句塞咗兩個原因、三個動作同一個例外時，按意思拆開，唔好按字數亂斬。
- 同一段避免連續重複「其實、同時、此外、因此」等寫作連接詞。

## Local without cosplay

- 避免將內地或台灣網絡用語直接扮成香港語氣，例如不合情境嘅「乾貨、賦能、避坑、入手、視頻、質量、信息」。
- 但唔做機械禁詞：引用、產品原文、指定市場語境要保留並標示。
- 地道感主要來自句序、具體動作、節奏同真實判斷，唔係方言 token 數量。
- 「講真、一嘢、save 低」等詞要有作用；口語詞包住一段指令摘要，仍然可能唔似這次要的 Threads。稱呼、代詞與語域要連貫，唔用刻意粗口、嘲諷或江湖語氣代表所有香港人。
- 安全／專業措辭按原意保留；L1 控制主張強度，不等於全文改用書面語。重寫後核對條件、急切程度與必要行動有冇被淡化。

## Human integrity

- 無第一身證據，就唔好寫「我試咗、我嚇親、朋友問我」。
- 無人物原話，就唔好補對白；無情緒 source，就唔好代人講「崩潰、震撼、後悔」。
- 可將抽象材料寫得易入口，但唔可以為自然感發明人、時間線、場景或結果。

## Final read-aloud pass

逐段讀一次：

1. 香港人會唔會咁樣順住講？
2. 有冇為地道而加咗太多語氣詞？
3. 每個短句係判斷，定只係被斬碎嘅長句？
4. 中英混用係因為習慣／準確，定純粹裝飾？
5. 刪走一句模板說話後，意思有冇損失？無就刪。
6. 對照實讀樣本，正文哪些句段呈現了本次選擇？語意分段、留白及自然節奏有沒有保留？不以符號出現與否判斷呼吸感，也不恢復已撤回的格式偏好。
7. 去掉版本名稱，是否仍能認出敘述與語氣差異？若只換字、符號或分帖方式，繼續編輯。
8. 若已有退稿 feedback，同一問題是否仍出現？未解決不能聲稱 style PASS；無樣本只可給有限度編輯判斷。
9. 每段是否向同一類讀者、保持同一說話關係？回應邀請是否符合當次目的、具體而容易接話？僅在 receipt 標示同行者，正文卻質問或訓話，仍未通過。
