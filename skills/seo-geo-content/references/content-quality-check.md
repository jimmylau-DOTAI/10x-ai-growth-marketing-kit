# Content Quality Check

## Intent

- [ ] Primary Query 清楚
- [ ] 開首直接回答查詢
- [ ] Content Type 符合搜尋者工作
- [ ] 每一段都幫助理解、判斷或行動

## Evidence

- [ ] 時效性資料已核實擷取日期
- [ ] 數字、法規、功能及引用可追溯
- [ ] 用戶提供資料與獨立核實資料已區分
- [ ] Inference 明確寫成判斷，而非來源事實
- [ ] 沒有虛構公司、案例、合作、價格或成果

## SEO

- [ ] Title、H1 及開首自然包含搜尋概念
- [ ] 小標題描述實際問題或結果
- [ ] Meta Title / Description 與正文一致
- [ ] URL slug 清楚簡短
- [ ] 內部連結有真實目的
- [ ] 沒有 Keyword Stuffing 或重複空話

## GEO / answer quality

- [ ] 重要問題有簡短直接答案
- [ ] 段落包含足夠上下文，抽出後不會誤導
- [ ] 來源接近相關 Claim
- [ ] Named entities、日期及適用範圍清楚
- [ ] 沒有聲稱保證排名或 AI Citation

## Reader value

- [ ] 有具體步驟、例子、比較或決策準則
- [ ] 有限制、取捨或不適用情況
- [ ] CTA 符合文章目的
- [ ] 香港語境並非硬加地名

## Status

選一個：

- `NEEDS INPUT`
- `DRAFT`
- `READY FOR REVIEW`
- `APPROVED`
- `PUBLISHED`（需要 URL 或發佈證據）
