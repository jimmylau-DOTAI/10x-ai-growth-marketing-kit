# 專門方法與交接

按已備材料同今次交件揀下面嘅一行。打開相對連結內嘅實際指引；腳本路徑跟隨指引所在目錄，品牌原料／輸出位置跟消費端 Project。已經確認嘅素材及方向直接傳落去。要單份交件就只用該分支。網站或圖片草稿、真實成品及外部發布分開驗收。

| 手上有咩／今次想要咩 | 用邊個做，交咩去下一步 |
| --- | --- |
| 新品牌，自己都講唔清想吸引邊個 | 用 [定位](../skills/hk-brand-positioning/SKILL.md) 交一句定位，再用 [內容策劃](../skills/hk-brand-editorial-calendar/SKILL.md) 將讀者常問嘅事變成欄目同日曆。想將全公司資料整理成可重用知識庫，先用 [公司建庫](../workflows/company-vault-builder/METHOD.md) 登記來源、逐題補公司卡。 |
| 有兩篇最似自己嘅舊帖，或者一堆參考、客人問題 | 用 [內容研究](../workflows/social-content-research/METHOD.md) 分出作者觀點、可核實內容同可借用手法，整理題目或共用 brief。要寫其他一般平台初稿就用 [社交文案](../workflows/social-post-writing/METHOD.md)；要 FB／IG 品牌稿用 [品牌文案](../skills/hk-brand-social-copy/SKILL.md)。 |
| 一份來源，想整一篇可搜尋、方便讀者引用嘅 Blog | 用 [SEO／GEO Blog](../workflows/seo-geo-content/METHOD.md) 定讀者問題、以答案開段、補證據及 CTA。已有定稿就直接用該文拆內容，毋須重寫 Blog。 |
| 已有 Blog，想一次出幾款 | 用戶已確認嘅原文由 Master 直接摘出共用事實；材料有待分析先用 [內容研究](../workflows/social-content-research/METHOD.md) 做來源摘要並確認，然後只行已要求分支：[香港 Threads](../skills/hk-brand-threads/SKILL.md)、[輪播文案](../workflows/instagram-carousel-studio/METHOD.md)、[口播／文字分鏡](../workflows/reels-text-storyboard/METHOD.md)、[Blog Banner](../workflows/ai-social-image-maker/METHOD.md)。每份成品標返對應事實、讀者及同一個下一步。 |
| 有帖文同真實圖片參考，想製作完整 IG 輪播 | 缺品牌視覺先用 [拆圖片風格](../workflows/image-style-lab/METHOD.md)，用 [輪播](../workflows/instagram-carousel-studio/METHOD.md) 鎖定逐頁故事、可見文字，再用 [製圖](../workflows/ai-social-image-maker/METHOD.md) 試封面。已確認風格及封面可直接續餘頁。驗收手機上文字、頁序及實際出圖。 |
| 有商品／服務，想製作銷售圖、人物封面 | [理解產品](../workflows/product-understanding-studio/METHOD.md) 核實賣點及買家問題，再由 [品牌商品圖](../workflows/brand-image-studio/METHOD.md) 將一個決策重點寫成圖文。人物主導嘅 IG 封面用 [人物封面](../workflows/personal-ig-cover-studio/METHOD.md)，要求有權使用嘅真實人物素材；只改產品背景用 [背景](../skills/hk-brand-product-backdrop/SKILL.md)。 |
| 想拍 Reels，或者已批稿想預覽一幕 | [口播稿](../skills/hk-brand-reels-script/SKILL.md) 適合只要錄音稿；要執行分鏡用 [文字分鏡](../workflows/reels-text-storyboard/METHOD.md)。已批腳本 → [9:16 HTML 分鏡預覽](../workflows/reels-html-storyboard/METHOD.md) → 已批畫面、要可播放樣片先用 [Remotion 一幕](../workflows/remotion-reel-scene/METHOD.md)。 |
| 手上有活動／服務，想收查詢 | [Funnel Builder](../workflows/sales-funnel-landing-page-builder/METHOD.md) 用受眾、offer、證據、CTA 交頁面稿同表單設計 → [Mira 受眾檢查](../workflows/mira-audience-qa/METHOD.md) 用第一次到訪者角度搵出阻力 → 原寫手修正。已有頁同 Blog、要將兩者接到同一個 Form 時，可用 [網站組裝](../workflows/landing-page-blog-deployer/METHOD.md) 做本機預覽。 |
| 想知道 IG 定 Threads 帶到查詢 | [UTM 連結](../workflows/utm-link-builder/METHOD.md) 用同一個活動名，為兩個來源各出一條可覆核連結。未有目的頁先出追蹤表。要測 Form→CRM，可用 Funnel 範本，以 TEST 查詢核對同一編號、來源同回條。已有成效報表先用 [廣告／內容成效檢討](../workflows/meta-ads-results-review/METHOD.md)，按活動目標選數據；如想預先揀廣告受眾，用 [廣告受眾](../skills/hk-brand-ad-audience/SKILL.md)。 |
| 收到客人電郵，要回覆同報價 | [Lead 回信及 Proposal](../workflows/lead-email-proposal-drafter/METHOD.md) 從來信抽出需要、讀已確認產品價目，分別交電郵草稿、Proposal 草稿及待確認條款。 |
| 呢次終於寫得似我，想下次都做到 | 用 [學習記錄](../workflows/company-vault-learning-loop/METHOD.md) 記低原句、修改、原因、適用情景；用第二個題試寫。用戶要求保存去知識庫時，用 [存返品牌庫](../workflows/save-to-vault/METHOD.md) 預覽落點、按授權寫入及讀回。 |
| 指名 ToAPIs 想試一個圖款，或將指定首幀做動態海報 | [指定模型出圖](../workflows/toapis-image-creator/METHOD.md) 或 [MiniMax 首幀轉短片](../workflows/toapis-minimax-h3-video/METHOD.md)。先確認模型、素材、預算及單次數量；未接服務可交完整製作 brief。 |

## 執行環境

文字策劃同寫稿可由現有品牌材料開始。已經有品牌庫或 Funnel Project 就用該工作目錄；第一次需要對應檔案結構，可另行解壓 [品牌庫範本](../assets/brand-workspace.zip) 或 [Funnel 範本](../assets/enquiry-funnel.zip) 到新位置。有公開版面參考先考慮 clone-website，要視覺層級或互動細節再檢查 design-taste-frontend、emil-design-eng 是否已安裝。圖片、Remotion、GA4／CRM 或付費模型依實際環境判定能交付嘅階段。

保留引入工具嘅 [來源聲明](../ATTRIBUTIONS.md)。對外部服務嘅發送、付款、部署及發布各按當次授權。品牌要保存新做法先用上表記錄流程；有明確排程需求先處理自動執行。
