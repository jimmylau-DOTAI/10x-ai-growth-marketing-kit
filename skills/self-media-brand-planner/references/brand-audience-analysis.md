# 由品牌證據到帳號定位

適用於新品牌、重新定位、客群太闊或兩組受眾有衝突。已有確認定位而今次只係交一篇稿，就讀返定案。先定範圍（全品牌、產品／活動、某平台帳號），再讀用戶已有嘅公司簡介、已匿名查詢、成交／未成交回饋、服務案例及認可舊帖。只有單一產品資料，只推斷該產品嘅情景。

## 1. 品牌可以憑咩發言

- 由一宗實例回溯：客人遇到咩問題、品牌點判斷、實際交付咗咩、有咩可核對結果。將創辦人個人經驗同全公司可持續交付嘅服務分開。
- 記低品牌角色、擅長嘅取捨、代表案例、人手時間、服務地區、資源同承諾界線。區分單次做過、已有重複案例、正在發展。
- 比較客人實際會採用嘅替代做法，包括自行處理。寫出一個會改變選擇嘅差別，附證據及適用條件。答案只有「專業」「優質」就返去搵例子。
- 交一句核心定位同一個支持案例。案例只可證明相應範圍，缺口記「候選」及要核對嘅材料。

## 2. 邊類客有需要，點揀優先次序

| 讀到嘅材料 | 可用嚟做咩判斷 | 要再核對咩 |
|---|---|---|
| 留言、收藏、常見搜尋 | 觀眾留意咩、用咩字眼、喺邊一步卡住 | 同一內容重貼合併；留意評論者有自選偏差 |
| 具體查詢、試用、報價 | 使用情景、買前疑慮、決定條件 | 查詢有冇變成訂單、實際由邊個拍板 |
| 訂單、續購、取消、流失 | 某段期間真實購買或流失嘅情況 | 真正動機要有客人回饋；單靠交易推斷標為假設 |
| 訪談、售後回覆、案例 | 客人點描述取捨、要咩證明先信、用後有咩改變 | 記錄時間、產品及樣本限制，保留相反意見 |

依要完成嘅工作或觸發情景分組。每組記使用者、提出需要嘅人、批預算嘅人；同一人兼任就直接寫。比較幾組嘅常見程度、品牌交付能力、每單價值、再購線索及接觸成本；只用有來源嘅項目，講明點解今期優先一組、暫緩另一組。規模／佔比要有期間、分母及來源。冇資料仍可按當期目標建議試邊組，附上一個能推翻建議嘅觀察。品牌長期客群、今期優先客群、帳號讀者分開定。

**交畀下一個方法**　主要客群及情景 → 要作嘅決定／主要顧慮 → 本人原話或店主觀察 → 證據及日期 → 仍要核對嘅一點 → 今期建議。報告保留角色、購買渠道、替代選擇、信任條件，前線稿件只取今次需要嘅部分。

## 3. 點樣由生意目標落到內容

先判斷業務階段（驗證需要、建立信任、帶查詢或服務舊客）。列一個今期目標、目前可用資源、要觀察嘅行為。只有可用數據先定量化基線。以優先客群起步，另問「未打算買嘅讀者，點解下星期仲會返嚟？」用實用、資訊、情緒或決策價值比較追蹤理由，選定後按[內容定位](positioning-decisions.md)試主題。
- 同一品牌可以有幾個帳號。分別記讀者、平台、用途、可持續提供嘅價值、格式、節奏、認可例子，同一個品牌事實由正本供應。
- 策略核對：定位講嘅優勢有案例支持？受眾實際擔心嘅事同今期目標對得上？想做嘅欄目有時間同材料？有衝突就指出邊項要收窄。
- 檢討回到原目標：保存可作實用性線索；有識別來源嘅查詢先計查詢；成交返查訂單。每個數據保留時段、平台、比較基準及限制。看到新證據先修訂受影響嘅客群或規則。

## 4. 同行、選題、拆稿各自交咩

1. **同行帳號**。跟今次決定比較相近業務、時段、格式及可見反應，抽查代表作及一般表現嘅作品，避免只揀成績最好嗰篇。分開記實際看到、合理解釋、未知因素。交一個以我方人手同素材可以試嘅做法，指出同行名氣、廣告預算或渠道差異。
2. **選題**。由客人常用字、產品抉擇、近期事件或已批准材料建立候選。原帖連結／ID 相同就合併，保留日期同來源；不同客人嘅獨立查詢保留各自依據。用讀者需要、品牌證據、今期目標及製作成本揀，為入選題寫一句推薦理由。交作者前查有冇用過同一題，重做時列明新材料。
3. **一篇參考**。拆出讀者原先點諗、開場提出咩問題、中段展示咩證據、轉折改變咩選擇、收尾要人做咩。交寫手一行「借〔鋪排〕、換〔自家案例〕、用〔已認可口吻〕」。一篇只作今次參考。
4. **多篇歸納**。將題材同講述方法分開整理，標明邊幾篇出現、有咩例外。同行只供研究結構，自家認可稿先用嚟抽取稱呼、句長、用字同語氣界線。只有轉寫文字就按文字分析，需要語調時補原音或本人確認。
5. **寫稿交接**。已有選題、角度、受眾、時長或字數就沿用。要揀方向就畀有實際開場嘅選擇及推薦理由；指定直接寫就交成稿。要代表老闆表態、資料又容許相反建議，先問會改變立場嘅一題。同一題做多平台，沿用事實同觀點，各自決定呈現方式。只交錄音稿時旁白獨立於分鏡指示。
6. **定稿同學習**。局部修訂保留其餘已選內容。用戶定稿先標記題目已用及稿件位置；定稿、發布、成效分別記。想長期沿用嘅改法，記改前／改後、原因、適用品牌及平台，換題試寫。新規則同舊規則有衝突，先找出兩者適用條件。

## 5. 資料不足、更新及保存

初次可由一句業務描述起候選。用戶自帶已確認資料就沿用；參考連結打唔開，可用提供嘅正文或截圖並註明限制。結論用「有來源支持」「品牌負責人判斷」「待驗假設」區分。同一渠道大量留言唔可以當整個市場分布。按新事實只更新受影響段落，記錄日期、依據、原決定及要重試嘅題目。品牌、受眾同策略結論互相矛盾就指出並交負責人定案。實際保存位置沿用 [品牌知識庫](brand-library.md)。

**虛構示例**　一間企業培訓公司收到三位 HR 詢問課綱，一位部門主管批過一次團隊培訓，公開帖又有前線同事問操作。可優先試一份畀 HR 轉交主管嘅實作成果示例；公司成交客群佔比仍然未知。前線帳號定位可以係「每星期示範一件返工即用嘅工作」，兩個試題係核對報價缺項、整理開會行動。下一次查詢核對邊個會使用、邊個批預算，以及需要咩資料先批。

## 6. 持續經營嘅工作記錄

完整經營任務開始時讀最近已定案嘅受眾、帳號目標、可用材料及未完成工作。以現有任務／週計劃寫一個可驗收成果、負責人、可投入時間。完稿連回題目；有發布證據先記作品、平台、實際時間／連結、觀察日期及數據出處。檢討時比較預期同實際行為，講明繼續、調整或暫停邊件事，以及下次要收咩證據。客人後續查詢、落單或流失理由回到原客群分析。一次修句毋須啟動整套。
