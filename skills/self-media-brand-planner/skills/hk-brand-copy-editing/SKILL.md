# 局部修稿與風格延續

執行時讀[第 97–98 頁原指令](../../references/source-copy.md)，保留相應步驟，依今次素材同指定交件調整。

先讀 [品牌與內容判斷](../../references/marketing-judgment.md)。

1. 先分辨要改嘅係港式用字、段落接駁、句式難讀，定係說服條件欠證據。鎖定指定段落及需保留嘅意思、事實、CTA。只改一句就直接交該句。

2. 想逐段選風格先從標題開始，為有實質差異嘅版本列開場及適用效果，用戶選定後將語氣延續去前言、正文、收尾。直接改稿就完成後一次過交。

3. 檢查新版本有冇偷偷加新承諾、改咗優惠或者抹走作者判斷。要解釋時展示原句、改句及一個改動理由。
