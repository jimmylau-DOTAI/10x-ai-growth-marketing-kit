# 由來源到 IG 貼文與封面

執行時讀[第 114、115、117 頁原指令](../../references/source-production.md)，保留相應步驟，依今次素材同指定交件調整。

先讀 [品牌與內容判斷](../../references/marketing-judgment.md)。

收到參考帖時，按[拆稿同寫稿交接](../../references/brand-audience-analysis.md)交代借用鋪排、自家事例同語氣；已有拆解直接沿用。

1. 打開用戶可用嘅文章、報道或逐字稿。分開可核實事實、不同來源有分歧嘅位同品牌觀點；如果只讀到標題就要求正文或改用已提供材料。已有品牌定稿，直接擷取同今次目的有關嘅事實。

2. 問「呢件事對我哋個讀者嘅選擇有咩改變？」用一個例子轉成平台文案。做封面時分三層：欄目名辨識系列；主標講讀者問題或收穫；副標補具體條件。三行各有功能。

3. 交 caption 同所需封面文字，事實可追溯返來源。活動日期、報名或品牌推薦用今次核實資料。多來源內容保留分歧，唔將二手推測寫成品牌經驗。
