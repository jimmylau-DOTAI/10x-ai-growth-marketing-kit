# 香港 Threads 寫作

執行時讀[第 120 頁原指令](../../references/source-production.md)，保留相應步驟，依今次素材同指定交件調整。

先讀 [品牌與內容判斷](../../references/marketing-judgment.md)。

1. 打開 [香港 Threads 寫作指引](writing-guide.md)。用現有素材定位作者喺件事入面嘅角色，開場可以由一個真實選擇、慣常誤會或者現場觀察入手。未有本人經歷就用一般情景，保留證據邊界。

2. 只要單篇就直接寫一篇。用戶希望選語氣先用同一材料試不同開場；主帖、回覆或多段按對話目的拆。要人分享經驗先用真問題，想人記得做一件事就用提醒收尾。

3. 交稿前將最後實際文字按段放入 JSON，用 [計數器](scripts/count_segments.py) 按寫作指引格式跑一次；超出上限就改稿再計。只將已確認嘅語氣更新帶返該品牌。引入嘅品牌通用指引見 [LICENSE](LICENSE) 及 [第三方說明](THIRD_PARTY_NOTICES.md)。
