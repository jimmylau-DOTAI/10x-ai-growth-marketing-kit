# 可錄製嘅短片口播

執行時讀[第 118 頁原指令](../../references/source-production.md)，保留相應步驟，依今次素材同指定交件調整。

先讀 [品牌與內容判斷](../../references/marketing-judgment.md)。

1. 找出一句觀眾一聽就認得嘅場景，跟住講一個轉折或容易忽略嘅條件。用手上事實示範個條件點改變做法，收尾畀一個可行下一步。

2. 按指定片長寫連續口語，讀出聲檢查換氣、資訊密度同節奏。只要錄音稿就交錄音稿；要求拍攝建議先另列畫面、停頓同屏幕字。估算時長標清楚。

3. 要比較語氣先交不同演繹。已揀一款保留作者立場；想延伸分鏡、HTML 或一幕預覽，去專門索引接下一步。
