# 品牌與自媒體定位

先讀[品牌知識庫](../../references/brand-library.md)嘅公司資料、現有定位及確認狀態。未揀平台都可以完成定位。已有定案，先展示原句同來源，接住用戶今次想改嗰一層。

按[三個定位決定](../../references/positioning-decisions.md)辨認要交品牌定位、帳號追蹤理由定內容主題。只問內容定位，已有帳號定案就行主題試題同取捨；三案只喺需要重新揀方向時做。

1. **分析品牌同客群。** 從公司資料整理產品類別、優勢、市場機會、替代選擇同目標客群。用[品牌與客群分析](../../references/brand-audience-analysis.md)分清讀者、使用者同付款人。交一句品牌定位同一項支持案例。
2. **搵客人痛點。** 讀查詢、訪談、購買回饋或實際使用情境，揀一個品牌有材料答嘅真問題。用戶只要搵痛點或想先睇一批候選，就按下面嘅分類清單格式交件。
3. **搵持續關注嘅價值。** 由痛點同品牌優勢發展實用、資訊、情緒、決策四種內容價值。完整練習配合網上搜尋，每類交 10 個構思；已有分析就接住用。市場發現同品牌實績分開寫。
4. **交三個自媒體定位方向。** 每案先交一個有明確角色嘅帳號方向；指定 IG 就先交帳號定位卡，再按下表交十欄。比較三案嘅角色、長期承諾同固定欄目，令同一批客都分得出各自嘅用處。按現有材料、差異同持續性推薦一案，寫一句內容範圍，交完等用戶揀。指定只改一個方向就照範圍交。

### 今次要用邊段原指令

喺[定位原指令](../../references/source-strategy.md)開相應頁，跟入面嘅任務交件。第 65 頁交品牌及產品優勢、市場機會、目標受眾；第 101 頁接客人四類痛點；第 69 頁用四種內容價值展開方向；第 71 頁交三案十欄。做 IG 三案，借第 74 頁由訪客角度驗帳號定位。揀定後要寫正式 Bio 先用第 76 頁。做內容定位先接第 83 頁四個支柱；原題每個二十題，現行每個十題，用普通描述。第 85 頁命名按用戶需要啟動。

### 客人痛點分析

先用已知嘅品牌或服務範圍、目標客群同處境縮窄材料。查詢、訪談、帖文留言、搜尋字同購買回饋都可提供線索。按產業同材料所見分組，下面四類可以做起點。

**用戶要一批痛點畀佢揀。** 合併重複問題，目標約 30 條，指定數量就照要求。按行業分組、全表連續編號，每項只寫一句客人口吻嘅問題。材料有限就列到有實質分別為止。用材料判斷關聯，未核實嘅情況用問句表達。輸出只交分類同問題清單，等用戶揀。

**做完整原課練習。** 按第 101 頁每類試 10 條。日常只為定一句品牌定位時，聚焦最影響選擇嗰幾條。

| 類別 | 要搵嘅問題 | 裱畫店示例（模擬） |
| --- | --- | --- |
| 購買掙扎 | 買前喺邊兩個選擇之間猶豫？ | 「呢張舊相配黑框定木框好？」 |
| 產品迷思 | 客人對產品本身有咩假設值得查證？ | 「框愈闊，係咪張相愈突出？」 |
| 技術迷思 | 客人點理解規格、用料或做法？ | 「標示防反光，係咪即係可以防褪色？」 |
| 場景痛點 | 去到邊個時間、地點或限制先發現有困難？ | 「我間屋西斜，張相應該掛邊幅牆？」 |

確認入選問題同業務、客群有關。用戶揀定並要求保存後，按[品牌知識庫](../../references/brand-library.md)只將入選問題補返目標受眾原頁，每項一句，已有嘅問題沿用原項。更新後交返原頁連結。

接自媒體定位時，可以將一條有依據嘅痛點連到追蹤理由，例如「每次想掛相，都可以返嚟睇同一張相配兩款框嘅實物比較」。

### 三個方向要揀到三種帳號

- 沿用已核對嘅客群。每案先鎖一個**品牌有資格做嘅角色**同一個**跨多個題目都成立嘅長期承諾**。三案可以面向同一批人，分別畀佢哋唔同嘅核心價值、固定欄目同返嚟理由。只有用戶想比較客群，先提客群替代案。
- 先試刪走所有單篇題目同商品例子，睇每案仲講唔講得清楚會長期提供咩。再試互換兩案嘅角色同長期承諾；如果仍然成立，重新寫清楚讀者返嚟會得到咩，並改用相應嘅欄目或做法。已確認題目只用嚟測試方向能否持續做。交件用欄目範圍同反覆使用嘅材料，毋須出新題或單篇帖稿。用實際做法講差異，市場未核對就保持「建議」。
- **指定 IG 時，每案先交一張帳號定位卡。** 用一個角色名同兩三句帳號層描述，驗訪客第一眼答唔答到：你係邊個、帳號做咩、點解關我事、你提供咩產品或服務、我憑咩信你。產品／服務寫品類或已核服務；信任位講帳號能持續展示嘅材料或做法，例如對照原規格、展示實物或用可公開案例。Bio 同置頂帖留到揀定方向再做。未指定渠道就沿品牌共用層做。

### 每個定位方向嘅十欄

| 欄位 | 交咩 |
| --- | --- |
| 品牌宣言 | 用一句易記嘅說話講出角色同佢為讀者做嘅事。 |
| 自媒體價值 | 用一句講清讀者持續睇會得到咩。 |
| 關注同每日返嚟嘅理由 | 寫出第一次想追蹤嘅具體處境，同咩需要再出現時會返嚟。 |
| 受眾共鳴 | 讀者會覺得邊一點講中自己？品牌嘅個性同視覺點樣表達嗰種感受？ |
| 獨特性 | 指出品牌憑咩經驗、專長或材料做到呢個方向。 |
| 內容主題類型 | 畀兩三個可長期重複做嘅欄目，每個講清楚會處理邊類問題；最多附一項現有／待補材料。 |
| 內容深度 | 說明喺原有客群最常遇到嘅問題上，仲可以深入提供咩實例、比較或方法。 |
| 目標受眾記憶點 | 交一個讀者下次會講返嘅招牌欄目、固定做法或視覺記號。 |
| 品牌傳播風格 | 跟角色定一種可示範嘅說話方式，等用戶揀方向後再定案。 |
| 受眾口吻嘅追蹤理由 | 以讀者第一身寫一句「我會 follow，因為……」，標明係模擬讀者口吻。 |

交完候選就等用戶揀。用戶揀定並要求保存後，依[品牌知識庫](../../references/brand-library.md)將定案同選擇原因補入原頁；已指定平台嘅做法放相應帳號頁。要求繼續選題先接[內容策劃](../hk-brand-editorial-calendar/SKILL.md)。

## 指定平台後點用

- Instagram 定位沿用三個方向、每案帳號定位卡同十欄。用戶有參考帳號可以讀[參考整理](instagram-positioning.md)。要檢查首頁，就按帳號名稱有冇方便搜尋嘅字眼、帳號類別、一句讀者價值、同受眾嘅關係、主題／服務／產品、聯絡方法及行動呼籲逐項睇。要起 Bio，就搜尋貼近香港受眾嘅用字，沿已選定位交 3 個簡短廣東話版本，帶出持續關注嘅好處、品牌視角同下一步，只用已核實嘅聯絡資料。指定改現有一句或指定份數就照要求做。
- Threads 按已選方向試一個值得討論嘅問題；Facebook 可按品牌讀者處境試案例或 FAQ；Blog 可按搜尋問題試深入解答。只要定位，交適用於該渠道嘅讀者、追蹤理由及一個例題。要求成品先交寫手。
