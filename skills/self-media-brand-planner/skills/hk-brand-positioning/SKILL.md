# 品牌與自媒體定位

先讀[品牌知識庫](../../references/brand-library.md)嘅公司資料、現有定位及確認狀態。未揀平台都可以完成定位。已有定案，先展示原句同來源，接住用戶今次想改嗰一層。

按[三個定位決定](../../references/positioning-decisions.md)辨認要交品牌定位、帳號追蹤理由定內容主題。只問內容定位，已有帳號定案就行主題試題同取捨；三案只喺需要重新揀方向時做。

1. **分析品牌同客群。** 從公司資料整理產品類別、優勢、市場機會、替代選擇同目標客群。用[品牌與客群分析](../../references/brand-audience-analysis.md)分清讀者、使用者同付款人。交一句品牌定位同一項支持案例。
2. **搵客人痛點。** 讀查詢、訪談、購買回饋或實際使用情境，揀一個品牌有材料答嘅真問題。用戶只要搵痛點或想先睇一批候選，就按下面嘅分類清單格式交件。
3. **搵持續關注嘅價值。** 由痛點同品牌優勢發展實用、資訊、情緒、決策四種內容價值。完整練習配合網上搜尋，每類交 10 個構思；已有分析就接住用。市場發現同品牌實績分開寫。
4. **交三個自媒體定位方向。** 每個先用一句講清「邊個會因為咩長期返嚟睇」，再按下表交齊十欄。三案要有唔同追蹤理由。按品牌手上有咩素材可以持續做，推薦一案，俾用戶揀。指定只改一個方向就照範圍交。

### 今次要用邊段原指令

喺[定位原指令](../../references/source-strategy.md)開相應頁，跟入面嘅任務交件。第 65 頁交品牌及產品優勢、市場機會、目標受眾；第 101 頁接客人四類痛點；第 69 頁用四種內容價值展開方向；第 71 頁交三案十欄。第 74、76 頁係指定 IG 首頁及 Bio 時用。做內容定位先接第 83 頁四個支柱；原題每個二十題，現行每個十題，用普通描述。第 85 頁命名按用戶需要啟動。

### 客人痛點分析

先用已知嘅品牌或服務範圍、目標客群同處境縮窄材料。查詢、訪談、帖文留言、搜尋字同購買回饋都可提供線索。按產業同材料所見分組，下面四類可以做起點。

**用戶要一批痛點畀佢揀。** 合併描述同一困難嘅句子，目標約 30 條候選，指定數量就照要求。分組後全表連續編號，每項一句，用客人平時會講嘅方式描述卡位。有原話或搜尋字直接支持就標「有來源」，從已知情境合理推演就標「待驗」。材料有限，列到有實質分別為止。第一輪只交分類同痛點清單，等用戶揀。

**做完整原課練習。** 按第 101 頁每類試 10 條。日常只為定一句品牌定位時，聚焦最影響選擇嗰幾條。

| 類別 | 要搵嘅問題 | 裱畫店示例（模擬） |
| --- | --- | --- |
| 購買掙扎 | 買前喺邊兩個選擇之間猶豫？ | 「呢張舊相配黑框定木框好？」 |
| 產品迷思 | 客人對產品本身有咩假設值得查證？ | 「框愈闊，係咪張相愈突出？」 |
| 技術迷思 | 客人點理解規格、用料或做法？ | 「標示防反光，係咪即係可以防褪色？」 |
| 場景痛點 | 去到邊個時間、地點或限制先發現有困難？ | 「我間屋西斜，張相應該掛邊幅牆？」 |

保留材料嘅出處供核對。用戶揀咗候選再補相關原話或搜尋字、原連結及已提供日期。有多份查詢記錄，可以核對同一問題有冇反覆出現。確認入選嘅問題同業務、客群有關，而且品牌有材料答到。用戶確認入選項同要求保存後，按[品牌知識庫](../../references/brand-library.md)補返目標受眾原頁，已有同一困難就補依據。

接自媒體定位時，可以將一條有依據嘅痛點連到追蹤理由，例如「每次想掛相，都可以返嚟睇同一張相配兩款框嘅實物比較」。

### 每個定位方向嘅十欄

| 欄位 | 交咩 |
| --- | --- |
| 品牌宣言 | 用一句易記嘅說話表達品牌喺呢個方向主張咩。 |
| 自媒體價值 | 用一句講清讀者持續睇會得到咩。 |
| 關注同每日返嚟嘅理由 | 寫出令目標受眾第一次想追蹤嘅處境，同下一次會返嚟睇嘅原因。 |
| 受眾共鳴 | 讀者會覺得邊一點講中自己？品牌嘅個性同視覺點樣表達嗰種感受？ |
| 獨特性 | 指出品牌憑咩經驗、專長或材料做到呢個方向。 |
| 內容主題類型 | 畀具體例子，睇得出個帳號平時會講咩。 |
| 垂直市場內容 | 指出會深入服務邊一小群人，同一個問題可以講到幾深。 |
| 目標受眾記憶點 | 同其他可供選擇嘅帳號相比，讀者會因為邊樣嘢記得你？ |
| 品牌傳播風格 | 定落品牌用咩聲線、語氣同表達方式跟讀者溝通。 |
| 受眾口吻嘅追蹤理由 | 以讀者第一身寫一句「我會 follow，因為……」，標明係模擬讀者口吻。 |

選定後，依[品牌知識庫](../../references/brand-library.md)將共用方向、依據及用戶明講嘅選擇原因存返品牌頁；已指定平台嘅做法存入相應帳號頁。要求定位就停喺呢份定案，要求繼續選題先接[內容策劃](../hk-brand-editorial-calendar/SKILL.md)。

## 指定平台後點用

- Instagram 定位沿用三個方向及十欄。用戶有參考帳號可以讀[參考整理](instagram-positioning.md)。要檢查首頁，就按帳號名稱有冇方便搜尋嘅字眼、帳號類別、一句讀者價值、同受眾嘅關係、主題／服務／產品、聯絡方法及行動呼籲逐項睇。要起 Bio，就搜尋貼近香港受眾嘅用字，沿已選定位交 3 個簡短廣東話版本，帶出持續關注嘅好處、品牌視角同下一步，只用已核實嘅聯絡資料。指定改現有一句或指定份數就照要求做。
- Threads 按已選方向試一個值得討論嘅問題；Facebook 可按品牌讀者處境試案例或 FAQ；Blog 可按搜尋問題試深入解答。只要定位，交適用於該渠道嘅讀者、追蹤理由及一個例題。要求成品先交寫手。
