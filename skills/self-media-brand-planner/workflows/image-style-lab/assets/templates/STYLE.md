# Style 名稱

## 風格核心

用一句話講辨識力；挑少量重要規律，用「R01 實際觀察 → 點解有效 → 新題材保留甚麼」寫 KEEP。用戶確認、跨圖觀察、推測分清。字形氣質／字重／描邊／閱讀層級屬此視覺 Style，不另開 TONE。

## 設計方法與變奏

FLEX 按內容及畫幅決定主體、文字、圖解的關係。來源位置只係觀察，不是未來坐標。系列共用質感／字體／色彩角色，封面、解釋、比較、收結可用不同閱讀路徑；只列今次有用的選項，不強制頁數、左右輪替或每頁放同一主體。為方便比較可沿用相同版面。說明跨比例如何重組，而不是裁切或等比縮小。

## 品牌適配

分開原圖色彩觀察與用家已確認品牌來源。正式版必須以自己的 palette 映射背景／主色／文字／強調角色，並替換來源身份與內容。未有資料就保留 reference-only；不得把參考色自稱自有品牌色。自然主體及真包裝不自動染色。

## 使用界線

AVOID 只記會破壞此風格、已確認不要或必要真實性界線。說明什麼是參考、真素材／proof 的要求、不可移植的原句／身份／claims；今次產品事實與 copy 留在 job。窄修改只改獲要求的部分，不寫成永久位置規則。Logo 依 job；乾淨角落係自然低細節背景，不造空框／紙牌／葉形 Logo 容器。
