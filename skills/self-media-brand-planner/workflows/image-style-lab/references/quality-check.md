# 對實圖檢查，而不是用總分宣稱靚

## 拆解品質

每項規律有原圖觀察與作用，不只列形容詞／色板。分清測量、估計與未知；KEEP 夠具體又能轉題材，FLEX 容許按頁面任務設計，AVOID 只收有依據嘅禁項。

有要求試圖才驗實圖；纯分析唔強迫生成。reference-only 可以保存候選，唔當成自己品牌正式版。brand-adapted／brand-approved 必須有實際品牌來源及 palette，確認記錄不能虛填。

## 新圖逐項看

- 第一眼有清楚訊息，繁中文字、解釋與例子可讀，唔靠縮細字增加教學密度。
- 字體氣質、主體關係、材質／光影、字圖整合保留選中品質。
- narrow edit 沒有改動未獲要求的範圍；新卡布局則配合資訊任務，唔機械複製前頁。
- 品牌色角色來自用家資料；自然主體和真包裝沒有不必要染色。只換色不代表充分轉化。
- 沒有照搬外部身份／文案／claim／Logo；authentic-required proof 有真素材。
- Logo 按 job 決定；未要求 Logo 時不加後期，也不畫裝飾空容器。
- 輸出數量、次序、封面與收結完整；actual size／copy／claims／素材另依 maker 驗收。

只寫具體觀察、缺口與改善。分數可作自用診斷，不用總分門檻替代用戶選擇、實際看圖或保存批准；不報 Style match %，不保證永遠靚。

## Pack 與證據

STYLE 的「參考圖片與觀察」（舊包才用 REFERENCE）嵌入本地可讀 current gallery，首張為正確封面／主示例，完整系列無任意數量上限；每圖 path 和 hash 同一 inventory row，來源／權利有記錄，舊版不冒充最新選中圖。無圖片複製權就交外部引用，明示不完整 portable。

新包只用一份 STYLE 仍需解釋具體機制及變奏；唔靠增加文件數證明拆得好。來源位置不是模板命令；同款可跨頁變化，有功能的重複亦可接受。字體處理在 STYLE，未被要求的文案語氣不另建 TONE。

validate_style_pack.py 查非空章節、metadata、圖片可解碼、hash 與路徑；不是品牌／審美／權利／模型行為驗證。保存候選、user selection、brand approval、format default、output QA、published 各自如實標示。

跨題材／跨比例／新 task 重用是有價值的進一步測試，但唔作每次窄修改或已批准保存的儀式。今次只測過一個題材，就照實記錄。
