# 將 Style 交到完整 AI 出圖

拆解與試圖可由同一 owner 接續；出圖階段讀當前可用的 ai-social-image-maker。只要求拆解時，不調用生成工具。用戶先要試感覺時，用短 brief 即可開始已授權的一張，不以完整 pack、第二題材或完整 Carousel plan 作额外門檻。

沿用現有 brief 或一份 CONTENT-JOB，唔為交接而重複建文件：用途／目標尺寸及依據、當次 copy／次序、selected Style／版本、品牌來源、少量最新 anchors、KEEP／CHANGE／AVOID、Logo intent、所需真素材／rights、輸出數量及有效批准。資料已有不重問；真缺內容或尺寸才問。

新格式只交一份 STYLE（已含設計方法及 reference gallery）＋必要圖片，不另生成 DESIGN。舊 maker 如果硬性要求五文件／DESIGN，明示 consumer 尚未相容；不要為通過它而將新 Style 拆回多份，也不暗改 maker。可交完整出圖 brief，但不宣稱已完成兩 Skill 端到端實測。

完整 native 圖要包括主體、構圖、光影、材質、閱讀路徑與可見文字；唔要求先做吉背景再排字。請 maker 按 runtime 能力與用戶要求生成／編輯；本 Skill 不另外指定相反的 finisher 路線。Logo／精確尺寸處理由 maker 按本次 job 和 runtime 規則執行，不能因此重做未獲要求的版面，也不能假稱像素完全保留。

品牌資料不足可继续 reference-only 拆解；正式品牌試圖必須帶自己的 palette／來源。authentic-required proof／產品標示／真 Logo 不可捏造或重畫當真實證據。完整 reference 圖集不必全送模型，但所有本次必要素材不能遺漏。

Logo not-requested 不自動建 Logo step；quiet corner 保持自然背景，不畫空紙牌／葉形／印章。若已安裝 maker 或其 references 跟本次 brief 有衝突，先回報精確衝突及能完成的範圍，不假稱兩 Skill 已接通，不暗改其他 Skill。修本 Skill 不等於 maker 已更新。

對新輸出實際看圖再回報：閱讀次序、字圖整合、機制保留、品牌適配、requested change 與 drift。失敗版本留歷史、不當新 anchor。完整尺寸／文字／產品驗收仍由 maker 負責；Style 選用／保存可以另外按批准完成，不把 preview 冒充 final。

沒有真 image-generation 能力就交準備好的 brief 和具體缺口，唔用 HTML 排版卡冒充完整 AI 成品。Handoff-ready 不是完成。
