# 從畫面到可重用方法

先看最新版實圖；一張都可以开始，跨圖共通性未知就標 unknown。不同用途先分組，唔把外部 inspiration、自己新版、已否決版本混成多款 Style。

## 拆解要解釋因果

用精簡表或自然段記「觀察 → 功能 → 新內容可沿用的方法」：
- 第一眼訊息、其後閱讀順序，主體和標題誰先被看到。
- 大標、解釋、註解的字形氣質、比例、行距、描邊／陰影；唔假稱識別 exact font。
- 主體比例、前後景、視線與文字關係；照片、插畫、模型感分清。
- 影響質素嘅光源、陰影、材質、紙感／毛髮／物件細節，而唔只寫「溫暖」。
- 色彩的背景／主要文字／強調角色；原圖色值係 observation，唔係用家品牌色。
- 文字密度與圖像功能：用家要教學豐富時保留解釋／原因／例子，唔以塞細字取代內容設計。
- 留白係閱讀節奏或自然場景，唔自動變成裝飾 Logo 空框。

抽少量有辨識力的 KEEP、可變 FLEX、AVOID；優先指出哪項改走就失去所選氣質。尺寸、品牌色和當次 copy 由 job／品牌來源決定。模板不是要求每張同坐標。

## 修改和頁面變奏

colour-only edit 鎖住原主體、字、構圖、材質，只改指定顏色角色；object edit 只改指定物件。新卡才按內容換布局。新用途範例：封面大訊息＋主體；解釋頁用局部示意與短解釋；比較頁用並列關係；收結用回顧＋行動。這些是起點，不是固定四張規格。

保留用戶選中嘅質素，唔為避免照搬就改成普通 stock photo 或泛用 infographic。新身份、新內容、場景或布局變奏須有功能，唔係隨機加裝飾。

## 有需要才測量

measure_reference.py 可量由 vision／人指定嘅區域 pixel 色值／比例；analyze_reference.py 只做統計摘要。兩者不會自動 OCR、識別字體／主體或取得品牌 token。精確要求才另存 regions／measurements，短分析不強制此檔案。

compare_rasters.py 只作適合情況下的 technical diagnostics，唔係 Style match %。真正驗證要看新成品的閱讀、質感、內容及品牌；比例／內容不同不能以 pixel distance 判定差。
