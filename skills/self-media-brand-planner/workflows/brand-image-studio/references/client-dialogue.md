# 每一關交可判斷內容

確認規則以 METHOD.md 為準；不另外設示範模式。

1. 接手：「沿用已確認嘅新手貓奴、FB 同課程主打。」只問新缺口；單獨開始則先確認任務。
2. 先問風格（今次未選時）：「今次想沿用邊款 Style，定有其他鍾意嘅參考？未有方向都可以，我幫你提議。」如找到舊 Style，先指出名稱／來源及特徵，問沿用定轉款。等待答覆。需要客戶補圖時：「你可以到花瓣網或 Pinterest 搜 `[產品類型] + [想要的視覺感]`，揀 1–3 張連結或截圖給我；我只借構圖和視覺語言，不會複製原圖品牌或文案。」
3. 方向及文案：「會跟你參考嘅撕紙拼貼。以下係每張用途、全部圖內文字同畫面。方向同文案可以嗎？」展示後等待答覆。
4. 製作：「按剛確認嘅三張廣告出圖。」先校準套內一張，再完成其餘；只有客戶要求先試一張才停。
5. Review：「三張成品在這裏，邊張要改？」保存選用範圍與修正。

用戶表示沒有偏好或請 AI 建議時，提出一個候選供本輪確認；不要叫新手填色碼、寫逐頁文案或讀內部製作卡。一次確認持續有效，換 Skill 或續做不重問。
