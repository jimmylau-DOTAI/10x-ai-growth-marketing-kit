# 來源、品牌與風格

事實、品牌及風格分工：
- 產品原資料／服務來源決定身份與可說內容。
- 已確認品牌規則與真 Logo 決定固定識別。
- Style／參考決定構圖、光線、材質、字圖關係及閱讀節奏。

先檢查本 Project 已確認 Style。用戶明確指定參考就沿用；多張有衝突且主次不明，才問一次。未有今次已選 Style，先按主指引問喜好並等待答覆；找到舊 Style 要指出名稱／來源及特徵，確認今次是否沿用，不能把檔案存在當成選擇。用戶沒有偏好或請 AI 建議時才提出一個候選，與完整文案交客戶確認後再生成；所有模式遵守主指引關卡。白底產品相只證明外觀。

如需要客戶自己補視覺參考，明確說可到 [花瓣網](https://huaban.com/search?q=%E4%BA%9E%E9%A6%AC%E9%81%9C%E5%95%86%E5%93%81%E5%9C%96&search_word_type=%E5%8E%86%E5%8F%B2%E6%90%9C%E7%B4%A2%E8%AF%8D&top=&original=) 或 [Pinterest](https://www.pinterest.com/) 搜尋，再交 1–3 張最接近本次方向的連結或截圖。只在參考真的有助選定風格時才提出，不把找圖變成開工門檻。可用說法：「你可以去花瓣網或 Pinterest 搜 `[產品類型] + [想要的視覺感]`，揀 1–3 張最接近的圖給我；我只會提取構圖、字圖比例、材質和閱讀節奏，不會複製對方品牌、商品、文案或人物。」

真看參考並按 [reference-deconstruction.md](reference-deconstruction.md) 提取結構。長頁按需要裁成可讀部分；mood board 選清楚主要畫面。只借視覺語言，不搬品牌、商品、文案、人物身份、價格、認證或成果。

辨認公司／店舖與商品品牌主次；可以調整場景配色來配合產品，不能改真 Logo 或包裝。服務畫面可用真實提供者、交付樣本或清楚標示的情境示意，不把生成角色當真講師／客戶。

打開真 Logo 核對比例、底色與細節。按 [native-images.md](native-images.md) 生成完整內容並預留乾淨位置，再放入原 Logo；模型重畫、空框或近似字標不能當完成。

Style 只維護一份，簡表見 [style-recipe.md](style-recipe.md)；不將單次候選自動寫成公司正式規則。記來源及實際讀取範圍，部分截圖不能冒充完整內容。
