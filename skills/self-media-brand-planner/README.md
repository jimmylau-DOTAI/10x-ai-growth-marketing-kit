# 品牌與自媒體定位 Master Skill｜Jimmy Lau

**幫香港品牌定清楚自媒體方向。** 畀 AI 公司介紹、認可案例同客人常問嘅問題，佢會用品牌做得到嘅事、客人痛點同四種內容價值，提出三個讀者值得持續關注嘅方向。你揀定之後，可以沿用同一份定位做選題、跨平台內容同讀者跟進。

## 點解要將成套工作交畀同一個小編？

你請一個小編返嚟，第一日會同佢講公司做咩、客人點解揀你、之前邊篇寫得似你。寫下一篇嗰陣，佢要記得上次點解揀呢個題目；客人留言問起產品，佢亦要知道品牌可以答到邊度。

Jimmy 嘅做法係將同一套編輯判斷教畀 AI。**公司資料決定有咩資格講，受眾需要決定講咩，帳號定位決定邊啲題目值得持續做。** 確定呢幾樣之後，先根據今次想讀者做到咩，決定用文字、圖像定影片。Master 負責接住上一步嘅決定，自動調用相應方法。

## 一個帳號點樣由零開始？

| 步驟 | 小編要答嘅問題 | 品牌會得到咩 |
| --- | --- | --- |
| 了解品牌 | 你提供咩產品或服務？客人喺咩情況會需要你？邊啲有事實支持？ | 可沿用嘅品牌底稿、受眾同今期營銷目標。 |
| 定帳號方向 | 目標客人今日未打算買，點解仍然值得追蹤你？ | 三個可比較嘅方向、建議及追蹤理由；確認後保存所選方向。 |
| 建立內容支柱 | 讀者想解決問題、了解新事物、得到共鳴，定係作選擇？呢個方向寫唔寫得成一個系列？ | 每個主題試十個具體題目，記低入選理由同材料。 |
| 選題同排期 | 今期優先答邊個問題？手上有咩材料？團隊有時間做咩？ | 每期嘅題目、角度、所需素材、形式同製作次序。 |
| 製作同修改 | 呢個題目要讀者睇完識做、值得收藏，定係想同人討論？ | 按用途寫文案、做輪播或 Reels；已選標題、語氣同事實一路沿用。 |
| 接住讀者反應 | 留言同私訊透露咗咩疑問？同原先想達到嘅目標有咩關係？ | 回覆草稿、要核實嘅資料、下一期可以接住做嘅題目。 |

## 同一品牌經營幾個帳號

公司資料共用。IG、Facebook 或其他帳號各有受眾、目的及認可風格，一個平台亦可以有幾款寫法。可沿用 Notion 工作台，或者將資料留喺品牌自己嘅檔案夾。[建庫、平台定位卡同保存方法](references/brand-library.md)

## 點樣叫佢開工？

> 我想你做我哋品牌嘅 AI 小編。呢度有公司介紹、兩篇舊帖同近期客人常問嘅問題。幫我定清楚個帳號值得追蹤嘅原因，再安排第一輪內容。我哋一星期做得到兩篇。

已經有定位同欄目，就直接畀佢今期題目。指定要 IG 輪播、Reels 或 Threads，佢會直接去相應製作步驟。想逐步參與，可以叫佢喺需要你揀定位、角度或語氣時停低。

**安裝**：將整個 `self-media-brand-planner` 資料夾放入 Codex Project 嘅 `.agents/skills/`。開新對話，用 `$self-media-brand-planner` 開始。將你已確認嘅品牌資料同上次定案放喺同一個 Project，之後可以由原進度接住做。
