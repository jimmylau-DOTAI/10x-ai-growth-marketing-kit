# Handoff Format

Use this compact structure:

```markdown
Status: FINAL_DRAFT_READY
Project: /absolute/path
Style: starter-c-product-visual v1
Route: starter_styles → HTML final
Cards: 10 × 1080×1350px
HTML review: /absolute/path/carousel.html
Final output: /absolute/path/output/
QA: PASS / issues
Learning: /absolute/path/reviews/run-id.md
Delivery: not published
```

If generation, export, automation, or publishing did not occur, say so directly. Never describe an HTML mock, a local PNG, or a requested CTA as delivered or live.
