# Handoff Format

Use this compact structure:

```markdown
Status: CAROUSEL_PLAN_APPROVED / IMAGE_HANDOFF_READY / FINAL_DRAFT_READY
Project: /absolute/path
Audience: approved audience
One message: approved message
Creator judgment: approved interpretation
Cards: 10 × 1080×1350px
Content plan: /absolute/path/content-plan.md
Preference profile: /absolute/path/PREFERENCES.md
Image Skill: ai-social-image-maker / IMAGE_SKILL_REQUIRED
Final output: /absolute/path/output/ / not produced
QA: PASS / issues
Learning: /absolute/path/reviews/run-id.md; candidate 1/3
Delivery: not published
```

If image generation, automation, or publishing did not occur, say so directly. Never describe an approved plan, local image, or requested CTA as delivered or live.
