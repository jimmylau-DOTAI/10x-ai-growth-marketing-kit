# HTML Review Contract

## Required

- One `.carousel-card` stage per card.
- Stage size exactly `1080px × 1350px`.
- Self-contained HTML and CSS; local asset paths are allowed.
- Editable semantic text, not baked-in screenshots.
- A global Style token block for palette, type scale, spacing, radius, and logo treatment.
- Safe margins of at least 72px unless the selected Style documents another tested boundary.
- Cards remain legible at a 320–400px mobile preview width.

## Review Surface

The HTML is a decision surface, not a fake promise that final AI images already exist. It must make these reviewable:

- story rhythm
- exact wording
- hierarchy
- content density
- CTA consistency
- logo position
- visual role of each card

## Forbidden

- Visible card numbers or pagination unless requested.
- Placeholder claims presented as fact.
- An entire plain background created only to accommodate a logo.
- Important text rendered as an inaccessible CSS background image.
- Hidden overflow that clips approved copy.

After approval, preserve a reviewed HTML snapshot before exporting or generating images.
