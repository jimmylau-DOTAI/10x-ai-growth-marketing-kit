# Auto deconstruction

## Purpose

Auto mode separates reusable identity from one-off content. It does not force every source into `STYLE.md`, `TONE.md`, and `SKILL.md`.

## Inspect three signal families

### Visual system

Look for repeated reading order, hierarchy, subject role, proof role, palette roles, typography geometry, material, spacing, density, and variation boundaries. A single colour or attractive object is weak evidence unless the user confirms it.

### Language system

Look for repeated point of view, reader relationship, Hook mechanism, sentence rhythm, vocabulary choices, explanation pattern, evidence behaviour, humour, and CTA behaviour. Separate public voice mechanics from exact phrases and personal biography.

### Work system

Look for repeated inputs, decisions, sequence, outputs, exception handling, approval gates, and observable quality checks. A topic outline is not a workflow; one polished output is not evidence of repeatability.

## Route internally

Create `AUTO-ROUTE.md` from the template. `detected_outputs` is a comma-separated subset of `style,tone,skill`.

- Use `target_use: portable` when no destination adaptation is needed.
- Use `seo-banner`, `ig-carousel`, or `ig-single-image` when that destination is known.
- Ask one destination question only when the answer changes the candidate.
- `save_target` stays `none` and `save_authorized` stays `false` until an explicit save command is received.

## Cross-layer boundaries

- Visual mechanics never inherit the source creator's identity, Logo, exact copy, or campaign claim.
- Tone never inherits source facts, personal history, signature phrases, or unverifiable authority.
- Skill never treats content order as an operational workflow without evidence of decisions and outputs.
- Shared evidence may support several layers, but each conclusion needs its own evidence note.
- If evidence conflicts, keep the conflict visible instead of averaging it into a generic Style or Tone.

## Student review

Present a short three-row summary: `畫面`, `語氣`, `做法`. Mark unsupported rows as `今次未見到足夠證據`; do not expose internal status codes. Then ask for one combined `保留／修改／不要／原因` response.
