# 使用真工具與看真圖
開始先讀實際可用圖像工具 schema；按 runtime 指定工具生成／修改。可用 native image 工具時直接調用，不能只交 prompt，亦不能以 HTML/CSS、底圖加字、拼色塊冒充完整 AI 圖像。修改前先打開本機素材。
在 prompt 清楚分工：原圖決定產品身份；Sheet 提供已核對角度與推演邊界；品牌檔與真 Logo 決定識別；場景 reference 只指導氣氛與構圖。沒有 schema 欄位不捏造參數。
用戶只給比例時，選工具支援的合適預覽解析度，說明是預覽尺寸；精確 pixels／平台版位有指定則跟指定。需求與輸出實测不同不得宣稱達標，不能拉伸產品湊尺寸。
先打開代表圖對照原圖或服務來源，再聯看五張理解圖，檢查同款 SKU／同一服務範圍、包裝形態或交付流程、操作、人物接觸、相對比例和資訊重複。只為硬錯誤圖重開原尺寸及修正；實際路徑、成功／失敗和例外集中記在 offer-notes.md（舊 product-notes.md 可沿用），不另建 manifest 或逐張長篇 QA。

用戶要求正式交付時才逐張完整檢查並記工具回傳定位、實際像素、問題、修正與版本。檔案存在不等於理解正確。

硬錯誤先做一次針對修正；仍錯就隔離該圖並繼續不受影響的批次，最後交已完成部分與具體未完成項。輕微風格差異記入例外，不阻塞整批。已確認的用途圖若改產品或動作，相關圖片才需重查。
