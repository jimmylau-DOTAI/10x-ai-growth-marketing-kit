# Product Form Lock / 產品形狀鎖

每次做產品理解或後續詳情／廣告圖，先建立並攜帶這張表：

| 欄位 | 寫甚麼 | 規則 |
| --- | --- | --- |
| format | 紙箱／軟袋／瓶／罐／盒等 | 必須有原圖或可靠實物來源支持 |
| front ratio | 可見正面寬高比例 | 用產品原圖估算，標明估算或量度 |
| hard/soft cues | 硬邊、折位、反光、封口 | 不可由平面圖憑空創作 |
| verified faces | 已見 front／side／back／top | 未見的一面不能生成作真實展示 |
| depth / opening / handle | 已核實細節及來源 | 未核實一律 `[Need confirmation]` |
| render rule | 每次帶哪張原圖，允許哪種視角 | 每張生圖都重新帶原圖，不能引用上一張 AI 圖 |

## 失敗條件

原本是紙箱卻畫成軟袋、原本是軟袋卻畫成硬盒、正面比例錯、加上未見手柄／開口／側面、包裝印刷被改寫，全部即時失敗。先修正來源或改為前視構圖，再談風格。
