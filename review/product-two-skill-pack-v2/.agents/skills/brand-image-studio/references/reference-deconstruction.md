# Reference Match：睇真一張，再換入我方產品

按用戶提供圖片／PDP 真正看圖。用戶指「呢張」便直接設為唯一 Primary reference；不要因為手上還有舊 mood board、品牌圖或另一款產品參考而平均混合。參考只控制視覺語言，不證明轉化或產品功效。

## 先處理看不清的參考

- 長頁：先裁成 3–6 個可讀 section，辨認 Hero、功能、材質、使用、FAQ 等模組；後續每頁附最接近該頁任務的 crop，不能只把整條細長圖交給模型。
- Mood board／社交九宮格：先裁出用戶指定或最接近交付用途的一格；整張 board 只作索引，不作生圖 Primary。
- 多張參考：只選一張 Primary；Secondary 每張只可補一個指定特徵，例如字體氣質或光線。

## 必須鎖定的八項可見結構

1. 畫布比例與閱讀方式：單頁、長頁 section、海報或社交卡。
2. 明暗基調：high-key／low-key，以及白色、淺色、深色的大面積比例。
3. 版面骨架：標題區、產品區、情境／材質區、資訊區、footer 的相對位置。
4. 產品比例：商品佔畫面約多少、置中或偏側、正面或場景內。
5. 圖像組合：packshot、寵物／人物、材質微距、生活場景各佔多少。
6. 文字層級與密度：大標行數、短副標、chips／labels 數量、留白節奏。
7. 分隔與裝飾語法：波浪、圓角卡、貼紙、箭嘴、花材、氣泡、線條等實際出現甚麼。
8. 光線與完成質感：自然光、柔光棚拍、清爽合成、手繪拼貼或其他可見攝影語言。

在 `04-reference-deconstruction.md` 只需輸出：Primary reference、八項 Style Lock、換入我方產品的方法、禁止搬入的身份／claim，以及一段可直接生圖的 Match Prompt。避免用「高級、好睇、creative」等抽象形容詞代替可見結構。

## 相似度快速判斷

將 reference crop 和生成圖並排並縮成手機小圖，檢查四點：整體明暗、最大色塊分佈、產品大小／位置、文字與圖片密度。四點有兩點明顯不同，就判 `REFERENCE_DRIFT` 並只修構圖／亮度／密度；不要另創新方向。例：參考是明亮藍白分段詳情頁，輸出變成黑藍專櫃、玻璃展台或電影場景，即使精美亦屬失敗。

保留我方商品相、Logo、文案與 claim boundary；不得搬參考的商品、Logo、價格、評價、認證、專有插畫或整句文案。包裝顏色可替換參考的點綴色，但 Primary reference 的明暗、版面與資訊密度優先。
