# 來源與視覺參考

記來源 URL／檔案、讀取日期、實際看到的範圍。部分截圖不算完整文章／Carousel／影片；沒有播放或媒體證據不分析影片細節。公開搜尋先找原始來源，登入受阻就用用戶提供內容或標缺口。

## 先取得能指導設計的參考

以下索取參考／等待方向的規則適用實際生成新風格圖像。若本次只做 Customer Insight 或文字藍圖，缺 Logo／reference 不阻止資料分析與候選視覺規劃；按 pdp-blueprint 標明出圖前缺口，完成文字任務後停止。

新方向未有合用參考時，Quick Batch 先按產品包裝、用途及現有品牌成品建立 candidate Style Recipe，並在交付提醒加入 1–3 張喜歡的參考可提高下一輪命中率；不因此停工。Review First 才先問：「可唔可以放 1–3 張你真心鍾意、想今次成品似嘅產品圖／詳情頁？唔使解釋設計術語。」已有用戶確認的參考／品牌成品可直接沿用並指出是哪一套。純產品白底相只能證明外觀，不等於風格參考。

參考必須先分角色：

| 角色 | 最多 | 用法 |
| --- | --- | --- |
| Primary style reference | 1 | 決定本次字體氣質、材質、構圖節奏與圖文關係 |
| Secondary detail reference | 1–2 | 只補一項已指明元素，例如撕紙、攝影光線或資訊卡 |
| Product truth / Logo | 不限 | 只決定產品外觀與品牌識別，從不當 style reference |

一張含很多品牌／貼文的 mood board 只可作「靈感池」；AI 必須先指出其中哪一格被選作 Primary，或要求用戶圈出／另傳 1–2 張。不得把十種不同風格平均混合成一張圖。每次只建立一個 Style Recipe，下一頁沿用同一條 Recipe；要換風格應另開一個 candidate，不可偷偷混入。

用戶沒有參考時，Quick Batch 可由 AI 提出具體 candidate 方向並內部校準，但須標明未經用戶選定，不可稱 approved style。Review First 可讓用戶選擇由 AI 找參考或自行提供。參考圖片要真正打開看，不能只讀檔名或從色碼猜風格。

## Style Recipe（出圖前必寫）

以一頁短表記下：Primary reference、可保留的 3–5 個特徵、次參考只補哪一項、不可用的元素、產品如何放進畫面、文字密度。這張表是 prompt 的唯一 style 來源；禁止把多張 reference 的所有形容詞一口氣塞入 prompt。

資料分工：產品／服務原始資料決定事實及身份；當前獲確認品牌文件與真 Logo 決定固定識別；視覺參考提供可轉用的構圖、光影、材質、字圖關係及閱讀次序。不能移植參考的原品牌、Logo、評價、數字或認證。舊 demo、其他產品的風格文件及估算色板不是當前正式品牌規則，須明確指出並確認是否適用。

## 品牌身份與產品主題一併處理

辨認公司／零售商品牌與商品包裝品牌是否不同。保留公司 Logo、字體氣質及已確認識別規則；從商品包裝提取主色、輔色、明暗、材質及品類氣質，讓畫面與產品相配。不要因公司常用米色就把所有產品都放進同一套米色模板。

有商品品牌廣告／詳情參考時，同時讀出它的色彩與視覺語言，不能只讀零售公司的色板。分清「商品品牌的共同識別」與「今次 SKU 的包裝標示色」；參考另一款的綠色包裝，不等於可把今次紅色包裝換成綠色。產品融入場景的具體規劃見 [product-detail.md](product-detail.md)。

讀取真 Logo，檢查透明／白底、長寬比、字標及細節。Logo 是受保護的品牌素材，不能交生圖模型「理解後重畫」。只有當現有工具可證明逐像素／向量保留原 Logo 時，才可把真 logo 合成到完成圖；否則生成畫面時必須保留乾淨 Logo Safe Area，之後由真實 overlay／版面工具放入原檔。未有有效 Logo 才問，不能自行重畫或默認空框作完成交付。

產品原圖與文案有 SKU、容量、顏色或包裝版本矛盾，要在出圖前集中提出，不能縮細、模糊或遮住規格掩蓋。保持真包裝，不因改畫面配色而重畫包裝。看不清寫未知，不把所有差異都歸咎生成模型。

實物可交簡短 product-reference.md：真實素材清單、已知規格、不可改變細節、缺少角度。真實原圖優先於 AI 生成圖；AI 畫出的背面、內部結構、尺寸不能變成產品證據，不要求補齊看不到的角度。外觀一致是檢查目標，唔承諾模型 100% 保留。

真看每張參考後，抽 3–5 個辨認特徵：主體關係、視角、光影／材質、閱讀順序、文字與畫面整合。寫保留甚麼、可以變甚麼、不能移植甚麼；估計色值／字體標估計。Style 唔等於色板或座標。

STYLE.md／DESIGN.md 只係 project-local candidate；已有 approved Style 先沿用。Quick Batch 用代表圖內部並排檢查後繼續，Review First 才停下等人確認。單次成功不宣稱跨題材通用，不用 pixel match 百分比冒充風格品質。
