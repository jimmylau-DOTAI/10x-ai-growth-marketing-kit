# 由參考資料到圖像計劃

先鎖定：圖片用途、受眾、主體、目標、可用證據、不可講的 claim、圖中文字語言、數量及尺寸。有產品原圖／Style／approved copy 就沿用；客戶聲音只用真正提供的資料，不把 AI 想像當市場研究。

按要求選擇圖像任務：

- 產品主圖：產品輪廓、顏色、比例與材質清楚，背景服務主體；不必加文字。
- 場景圖：展示真實合理的使用場景，換人物／背景亦維持同款產品。
- 細節／功能圖：只放大有原圖證據的零件、材質及已確認用法，不虛構背面、內部或尺寸。
- 詳情頁圖片：每張解答一個購買疑問；按實際需要安排介紹、細節、用法、適用範圍，不硬填十張。
- 服務／活動／廣告圖：用一個清楚視覺主張，配必要短標題／CTA；不捏造場地、人物身份或成果。
- Banner／Carousel 圖：沿用已確認主張與逐卡文案，按各圖尺寸及閱讀次序設計構圖，不另寫文章或 Caption。

圖中文字限短標題、標籤、賣點與 CTA；無字圖的 exact visible copy 記「無」。用戶未提供必要圖中文字時，可依已確認事實提出精簡版本供審核。價格、規格、公司結果等未知標 TBC，不把未知放上宣傳圖。平台規格需要時讀當次官方文件。

## 設計推導：動機 → 主張 → 視覺

每張先回答「邊個睇、佢正猶豫乜、睇完要明白／相信乜、想佢做乜」。受眾動機是依 brief 推測就明示，不冒充訪談或數據。主圖、賣點頁、使用頁不必都放 CTA；各自承擔辨認商品、理解價值、降低使用疑慮的角色。

在同一份簡短 plan 留以下決定，逐項有理由，不用每項另開文件：

- **視覺主張：**一張只服務一個主要訊息。主體大小、鏡頭、動勢／靜態與場景如何幫人理解它；不能只把所有賣點排成卡片。
- **配色角色：**分清固定品牌識別、包裝主／輔色、背景／文字／點綴色。由包裝及參考決定對比或和諧；避免多套色盤爭主角。正式品牌規則有硬限制時遵守，衝突則提出選項，不能自行改 Logo 色。
- **構圖及光影：**從哪張參考學主體佔比、留白、視線次序、攝影角度及材質。光線要帶出包裝形體；背景與產品要有分離，不能深色產品融入深色背景。
- **字體與文案：**字體氣質跟品牌／包裝，標題要服務主張；在實際手機閱讀尺度檢查，避免巨型標題擠壓產品。圖示有助理解才用，不能拿通用 icon 代替視覺概念。
- **Logo：**真實素材、位置、比例、留白與對比；它要看得到又不搶產品。不要將 Logo 空框當成設計元素。
- **取捨：**每個裝飾應能說出它對產品／主張的作用；無關的樹葉、光斑、線條或平台座不要慣性加入。有意保留的細節也要服從焦點。

### 如何與用戶確認

對用戶只講簡短方向、必要圖中文字與各圖目的。例如：「用包裝深藍做主調、紅色帶出重點，淺色區域襯返公司 Logo；產品做視覺焦點，參考 A 嘅棚拍光影。三張分別講商品、選購理由、點用。」這是說明方法，不是所有商品的預設配色。

背後 plan 留每張目的、exact visible copy、source、場景／構圖角色、尺寸、reference／Logo 素材及已確認範圍。先做最能驗證風格的**代表圖**：如果整套有文字及賣點，單靠無字白底圖不足以驗證排版，宜先做一張有產品、Logo、主標題與核心賣點的詳情圖。Quick Batch 由 AI 自行檢查產品、Logo、claim 和基本可讀性後繼續整批；Review First 才先讓用戶睇圖並等待方向確認。

成套沿用配色角色、攝影質感、字體層級與 Logo 處理，構圖按各頁目的變化。不要把首張重複貼三次，也不要三張各自設計成不同品牌。

成品不能出現 TBC 佔位當真實宣傳；缺事實就刪該主張或停該部分。不同平台重新安排用途、比例與文字密度，唔一張圖當全部平台完成。
