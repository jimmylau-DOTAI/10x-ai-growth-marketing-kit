# 逐圖分鏡與生圖交接

本規格由 AI 填寫，學生只交產品資料及 reference。不新增第三個 Skill，也不為每張圖建立一份 MD。

## 先分清交付
- 主圖／gallery：重點是辨識、細節與選購比較。
- 詳情頁：按購買問題安排連續閱讀，一屏一個重點；承接 pdp-blueprint。
- 廣告：每張一個有來源的購買主張、場景與行動。不同動機不是不同品牌風格。
- 七類「主圖、核心賣點、材質／結構、使用場景、功能參數、尺碼規格、顏色選項」是覆蓋檢查，並非必須七張或七格。一類可多張，數類可在同一購買問題下合併；未證實項省略或留待補資料。

先沿用知識包的來源與原圖；缺覆蓋表則在本次計劃補類別→來源／原素材→採用／合併／省略及原因。顏色選項只有真實版本與對應原圖才做，未知尺寸不畫尺規。不以廣告 reference 證明本品功效。

## 每張一張製作卡，集中存放
詳情頁寫入既有 `05-product-detail-blueprint.md`；gallery／廣告寫入 `06-creative-plan.md`；混合任務各存所屬文件，使用穩定 image_id 互相引用，不複製整套資料。每張記錄：

1. **身份**：image_id、交付類型、頁次／版位、比例、語言、當前版本。
2. **任務**：一個購買問題、這張的溝通目的、覆蓋類別；廣告註明候選購買動機。
3. **證據**：F-ID 與 source／scope；核心特點→有支持的優點→買家意義→證據。利益若只是偏好推測，不寫成保證。缺口和禁止 claim 放製作備註。
4. **對外文案**：實際 headline、必要的 subheadline、labels／CTA；逐字寫好，按版面需要決定數量，不強迫每頁三個 icon。製作註記不得混進圖中文字。
5. **視覺分鏡**：第一眼焦點、產品／細節比例與位置、前中後景、構圖、視角、光線、材質呈現、圖文區域。每項服務本頁問題，不是每張固定產品佔 46%。
6. **場景與動作**：人／寵物、背景、具體可行動作；多張場景要有差異，同一操作步驟可連續。純規格或材料頁不必加貓或模特兒。
7. **實際輸入**：真產品原圖路徑與 SKU、需要的細節原圖／已核對示範、單一 Primary reference 或可讀 section crop、真 Logo 路徑及沿用的 Logo 處理方式。標明每張素材是身份、用法還是風格參考。
8. **一致性**：沿用已選視覺規範與 Form Lock；列這張不能改的產品細節，及要保留的 reference 結構特徵。

先決定焦點，再安排其餘資訊。主圖突出商品；細節頁可讓局部大於完整包裝；使用頁展示動作；規格頁優先清晰比對。Design System 固定色彩角色、字體層級、間距節奏、光線、圖形語言及 Logo 規則，不固定每張構圖。長詳情 reference 按相應章節取用，不能所有頁都照 Hero。

## 發送給生圖工具：一次一張完整交付圖
每個生圖任務只接收：本卡的對外文案與分鏡、相關原素材、當前 Primary reference、必要的產品與風格鎖定，以及輸出比例。不要把全套藍圖、七類清單、其他頁文案或五款停用風格放進 prompt。

明寫「只生成 image_id 對應的一張完整圖片；不要總覽、聯絡表、多頁拼貼」。單頁內合理的操作三步／比較模組可保留；那是本頁內容，並非把三張成品縮成一張。五款風格比較若用戶指定，建立五個獨立任務，不變成整套詳情頁。

Quick Batch 可連續或按工具能力批次處理多個獨立任務，不需每張等用戶；用戶只要 Page 01 就只發該卡。「只要藍圖」不發生圖任務。工具只有 prompt、沒有輸出檔，就記 not_generated。

## 對學生顯示
只展示「圖號｜主題／購買問題｜主標｜畫面重點」簡表與重要資料缺口，不鋪開所有製作卡。Quick Batch 繼續製作已要求成品；Review First 交真正代表圖後才停。學生不用先閱讀或批准八欄表。輸出後對真原圖、當頁文案及 Primary reference 核對，不以寫過分鏡或自評分數當成視覺通過。
