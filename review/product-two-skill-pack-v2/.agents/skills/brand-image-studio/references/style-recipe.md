# Style Recipe / 學生參考圖轉譯

這一步避免「畀十張圖，AI 拎晒全部元素混成一張」的雜亂結果。

## 學生只需做一件事

上傳 1–3 張自己鍾意的成品參考圖，並說「想似呢張」。不需要寫色碼、字體或長 brief。用戶只給一張就直接用該張，不要求補足數量。找圖可先用花瓣的 [亞馬遜商品圖搜尋](https://huaban.com/search?q=%E4%BA%9E%E9%A6%AC%E9%81%9C%E5%95%86%E5%93%81%E5%9C%96&search_word_type=%E5%8E%86%E5%8F%B2%E6%90%9C%E7%B4%A2%E8%AF%8D&top=&original=) 或 [Pinterest](https://www.pinterest.com/)；只學視覺語言，不搬其他品牌、包裝、價錢、優惠、評價或認證。

## AI 必做

1. 真看圖片；長頁先裁 section，mood board 先裁指定格。用戶指明的圖直接是 Primary，不另行投票。
2. 用一句自然語言講清楚要跟的可見結構，例如「明亮藍白、直向分段、產品與材質／生活照交替、中文大標配短 labels」。
3. 寫一張短 Style Recipe：版面骨架、明暗、色彩比例、產品比例／位置、圖像組合、文字密度、分隔裝飾、光線，以及不可搬入內容。
4. 先輸出一張符合最終用途、縮圖看也屬同一視覺家族的 preview；PDP 就做真正 PDP section，廣告才做廣告。不得以「重新詮釋」為理由轉成 reference 沒有的專櫃、電影、科技或極簡風。
5. Quick Batch 由 AI 內部檢查 preview 後立即生成同組圖片；Review First 才等待用戶確認。所有圖沿用同一 Recipe，人物／貓／情境可以變，但字體氣質、紙張／攝影、圖文節奏不能每張重置。

## 必守

- 產品原圖只決定產品真實外觀。
- 選中的 Primary reference 才決定 style；它不是產品／品牌／claim 的來源。
- 每次生圖重新附 Primary reference 或對應 section crop，不能只交文字 Style Recipe。
- 產品包裝色用來替換點綴色，不可推翻 reference 的明暗、版面骨架和資訊密度。
- 原 Logo 以 overlay 放入，不用 AI 重畫。
- reference 有價錢、促銷、療效或其他品牌，除非本 job 已核實，否則一律不帶入。
