# 理解預覽：先判斷是否需要

預覽用來解決具體疑問。原資料已清楚可直接核對；不預設五張、不為進入設計湊圖。客戶明確要求的圖片仍按要求完成。

| 疑問 | 先核對 | 有幫助時才提出 |
| --- | --- | --- |
| 產品同款／外觀正確 | 原相、標籤、版本 | 外觀總覽 |
| 材質／細節理解正確 | 實物特寫或官方資料 | 局部說明 |
| 開啟／安裝／使用 | 手冊或真實操作資料 | 步驟預覽 |
| 服務流程難理解 | 實際流程與條件 | 流程圖 |
| 方案／交付容易混淆 | 本服務方案、交付樣本 | 比較或交付說明 |

在研究筆記列問題、來源／素材、建議預覽與張數、可見文字、限制。客戶確認後才製作，可與理解確認同輪完成；已有明確批准則沿用。

沒有背面、尺寸、操作、案例或效果證據時，先補來源或換受支持畫面；不能生成看似合理的圖作證據。原相、示意與未確認項分清。理解預覽不放促銷或效果承諾，與正式銷售圖分開。

零張預覽是正常路徑；已選預覽失敗則記具體缺口。只阻塞依賴該未知內容的成果，其餘可繼續。
