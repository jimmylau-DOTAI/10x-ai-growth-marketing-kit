# 一份研究筆記

使用 `offer-notes.md`；已有 `product-notes.md` 或等效資料直接沿用。保留以下內容，不另開重複摘要：

1. 任務：類型、受眾、市場、用途、主打、CTA、交付要求及已確認範圍。
2. 事實與來源：特點／服務內容 → 來源及條件 → 買家意義 → 可用文案。推測與 TBC 分開；既有來源 ID 沿用，沒有則用清楚連結或位置。
3. 買家問題：真實問題與 AI 候選分清，只保留影響購買判斷的項目。
4. 素材及邊界：原產品相／服務資料、真 Logo、參考的實際路徑；已核對與缺失項目。
5. 狀態與交接：客戶修正、有效確認、必要視覺檢查、已選預覽及實際結果、下一個成果。

## 分支查漏

- 產品：名稱／版本、款式／容量、外觀、材料／成分、功能依據、使用／適配及限制。只記適用項目；不由重量猜尺寸、由包裝猜質地。
- 服務：對象、問題、包括／不包括、方法／流程、交付、方案／價格、時間及參與條件。按課程、顧問、代辦等實際交付核對；不由宣傳照猜成果。
- 混合：分列兩種事實與套裝關係，不讓服務承諾變成產品功能。

已看原資料才標核對；客戶確認表達方向不等於提供了效果證據。研究內容可以多於最後圖片內容，不為配合張數刪重要限制。
