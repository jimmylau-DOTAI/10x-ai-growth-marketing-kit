只製作已確認問題與張數。先看原素材並讀可用工具 schema，依 runtime 規則調用支持的圖像工具；不捏造欄位，不用 prompt 冒充圖片。完整 AI 圖像不以 HTML／CSS 或底圖加字代替。

每次只帶該預覽的真實資料、可見文字、畫面要求與邊界。產品原相決定身份；服務來源決定流程／交付；參考只決定呈現。涉及品牌識別須保留真 Logo，不由模型重畫。

沿用已確認用途及比例；沒精確像素時使用工具合適的預覽尺寸並說明。指定尺寸要量實際輸出，不能把 prompt 尺寸當已達標或拉伸產品。

實際打開每張預覽，核對其問題、文字、外觀／操作或服務內容。一次針對修正仍失敗則記未完成；額外付費重試須在已授權額度內。客戶只需核對仍有疑問部分。

路徑、狀態、來源及確認記回研究筆記，不逐張另建報告。缺工具就交已完成研究及限制，不稱已有圖像。
