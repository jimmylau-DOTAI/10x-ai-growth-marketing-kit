# 其他圖片與配套文案

只做本次已要求類型與數量。先讀主指引，以下不另加確認流程或固定套裝。

- 多張廣告：按已確認數量分配不同購買動機與構圖，共用風格。單張只做所選主張；沒有足夠不同內容就提出取捨。
- Gallery：按用途選辨認產品、細節、使用、規格或選購比較。未知內部結構不用想像補完。平台正式主圖須核對當前官方要求。
- Listing 文案：按指定平台與欄位寫標題、描述、bullets、FAQ 或 CTA；不自動附加完整 SEO Blog。
- Meta 廣告文案：按要求提供配圖的 primary text、headline、description、CTA，與落地頁資訊一致。
- Google 文案：只提供要求的 Search／Display 等欄位或指定素材包；沒要求不擴成關鍵字、feed、負面關鍵字及多平台計劃。

平台當前字數／版位規格需要時查官方來源，未核實只能稱草稿。文案用已確認事實，不編優惠、評價或承諾。素材差異不等於已證明 A/B 成效；投放、預算與帳戶操作不在本 Skill。
