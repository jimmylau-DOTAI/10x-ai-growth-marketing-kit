# 風格方向

有已選 Style／參考時沿用，創意放在同一風格中的場景、角度及內容。沒有時從 offer、受眾及品牌資料提出一個候選；客戶要求比較才提出多個。

一個方向只需說清：希望買家感受到甚麼、主體與文字怎樣安排、色彩／光線／材質、與來源或參考的關係。避免固定電影感／雜誌感模板。

風格方向與廣告購買角度分開：三張廣告可以有三個動機，但共用一套風格。只要一張就不必先寫三個預案。

按 SKILL.md 展示方向及完整文案，確認後才生成套內代表圖。代表圖要具備真實交付的資訊結構：詳情頁驗詳情頁，廣告驗廣告，不另加無字風格測試圖。

客戶覺得唔靚時，對照參考指出構圖、焦點、字量、光線或融合的具體問題，提出修正；方向有變重新確認。保留產品真實性、服務範圍及原 Logo。
