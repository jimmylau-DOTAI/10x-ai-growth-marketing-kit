# 買家問題與可用回答

已有研究足夠就沿用，只有缺口才補分析。按要求讀評論、Q&A、客服或社群資料；公開搜尋以已授權範圍為限，不延伸成全面競品調查。

保留對本次成果有用的「問題／阻力 → 來源或推測 → 本 offer 可用回答 → 對應頁／主張」。單張廣告聚焦一個主要問題；詳情頁選能影響購買判斷的不同問題，不固定 10 問、5 痛點、5 阻力或評分表。

真客戶聲音保留來源與讀取範圍，AI 候選問題明確標示。產品說明不是客評；評論反映擔心甚麼，不證明本品功能或服務效果。沒有樣本就不能稱「最多人關心」或計百分比。

用本產品事實／服務範圍回答，不挪用競品案例、評分、頭像或認證。未有支持的回答記缺口，不製造痛點或保證。

結果寫回現有計劃，已有 customer-insights 文件可沿用。客戶看重點問題、回答及主打建議，不需審內部編碼。
