# 沿當前關卡續做

在現有計劃保留已完成項目、有效確認、版本及下一動作。「下一步／ok／做晒」依當前展示的內容解讀，不自動新增張數、平台或跳過尚未展示的關卡。

- 任務／理解尚未確認：取得該關答覆再前進。
- 已展示方向及完整文案，客戶確認／說「出圖」：按該版本及範圍製作。
- 只要藍圖：文字交付後停止；後續指令若未清楚要求生成，先說明下一個可做成果，不能自動出 Page 01。
- 批量已批准：套內第一張校準後完成其餘，不逐張重問。
- 先試一張：交圖等待答覆；只有一張的授權不延伸成整套。
- 小修改：依明確指令修改相關頁，重驗新版本；主打／風格／關鍵文案改變則先展示修訂計劃確認。
- 客戶說唔靚：停未開始的批次，指出與參考或任務的偏差，回到方向修正。
- 缺素材／工具或生成失敗：列影響及已完成部分，繼續獨立工作；付費重試遵守現有授權，不能無限重試。

成品 review 展示實際圖像、完成數、重要問題及下一步。版本、檢查、確認範圍記在現有計劃；不以檔案存在或測試通過冒充客戶選用、平台可用或廣告成效。

正式尺寸／final／交客才跑 output-contract 的完整驗收；創作前關卡與批量方式不因此改變。
