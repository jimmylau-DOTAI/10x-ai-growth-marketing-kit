# 詳情頁文案與製作計劃

用一份 `creative-plan.md` 或既有 blueprint 記全套內容，不另開逐頁文件。指定數量／語言／比例優先；未指定則按購買問題提出張數，與本輪方向及文案一起確認。長頁可增加深度，不因 Shopify 自動轉十頁或英文。

每頁按 [image-storyboard.md](image-storyboard.md) 記買家問題、來源支持的回答、完整對外文案、畫面與素材。詳情頁要足以解答該頁問題，不能只有一句標題；說明段、步驟、標籤或比較模組按需要選，不硬湊 3–4 個。

用 [product-detail.md](product-detail.md) 的產品／服務內容排讀序。產品先讓人認得商品再解釋選購理由；服務先讓人明白對象與內容再解釋方法及交付。先後可隨主打調整。

## 證據不足

缺材質、尺寸、成效或優惠，只用已確認內容或換購買問題，不畫假尺規、不造數據／折扣。若用戶指定張數而資料不足，列可合併／替換方案，說明仍未完成部分，不靜默減數或湊假賣點。

TBC 與製作缺口留在備註，不放成宣傳主標。買家必要的適用限制要保留。缺 Logo／參考仍可完成文字藍圖，列出出圖依賴。

## 確認與出口

給客戶看全部實際對外文案、各頁用途及畫面安排，共用一份 Style／品牌規則。確認後按已選批量或先試一張方式生成。「只要藍圖」到文字交付就停。

詳情＋廣告共用計劃及來源；廣告另外濃縮單一訊息，不把詳情頁縮小當廣告。代表圖計入所需張數。
