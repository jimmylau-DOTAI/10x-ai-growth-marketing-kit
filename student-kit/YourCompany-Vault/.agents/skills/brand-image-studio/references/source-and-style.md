# 來源、品牌與風格

事實、品牌及風格分工：
- 產品原資料／服務來源決定身份與可說內容。
- 已確認品牌規則與真 Logo 決定固定識別。
- Style／參考決定構圖、光線、材質、字圖關係及閱讀節奏。

先檢查本 Project 已確認 Style。用戶明確指定參考就沿用；多張有衝突且主次不明，才問一次。未有 Style 可提出一個候選，與完整文案交客戶確認後再生成；所有模式遵守主指引關卡。白底產品相只證明外觀。

真看參考並按 [reference-deconstruction.md](reference-deconstruction.md) 提取結構。長頁按需要裁成可讀部分；mood board 選清楚主要畫面。只借視覺語言，不搬品牌、商品、文案、人物身份、價格、認證或成果。

辨認公司／店舖與商品品牌主次；可以調整場景配色來配合產品，不能改真 Logo 或包裝。服務畫面可用真實提供者、交付樣本或清楚標示的情境示意，不把生成角色當真講師／客戶。

打開真 Logo 核對比例、底色與細節。按 [native-images.md](native-images.md) 生成完整內容並預留乾淨位置，再放入原 Logo；模型重畫、空框或近似字標不能當完成。

Style 只維護一份，簡表見 [style-recipe.md](style-recipe.md)；不將單次候選自動寫成公司正式規則。記來源及實際讀取範圍，部分截圖不能冒充完整內容。
