# 接住確認與素材

優先讀當前研究筆記及原資料，承接受眾、市場、用途、主打、CTA、語言、張數、素材與有效確認。等效資料直接使用，不重做問卷、不要求固定五張理解圖。

- 產品：本次款式／版本、外觀、規格及已確認操作；原相優先於生成預覽。
- 服務：對象、範圍、方法／流程、交付、條件及已證實資歷／案例；不要求產品角度或外觀總覽。
- 混合：分開兩種事實與套裝關係，共用任務及確認。

重要主張要對回來源；既有 ID 沿用，沒有則用可查連結／位置，不為編碼重寫研究。未知不能補成事實；尚未核對視覺要保留限制。理解預覽可為零，但已選未完成項目不能隱藏。

只有新缺口／改動才提問。單獨開始本 Skill 而未確認任務，按主指引完成開場；核心事實不足則補該部分，不強迫重跑全套理解。文案工作可在缺圖片／Logo 時繼續。

同工作區重用素材，轉工具只帶該圖需要的資料。工具收不到原素材就說明限制，不虛構已傳送或素材路徑。
