# 一份可重用視覺規則

只把參考拆解與已選方向整理在同一計劃，不另寫重複 Style 文件：

| 項目 | 記錄 |
| --- | --- |
| 依據 | 已確認 Style 或主要參考，次參考補甚麼 |
| 版面 | 主體位置／比例、讀序、圖文密度、留白 |
| 質感 | 色彩角色、字級、光線、材質、裝飾 |
| 一致與變化 | 全套保留的特徵，每頁按問題改的構圖 |
| 品牌與事實 | 真 Logo 位置、產品／服務不可改項、禁止搬入內容 |

只寫會影響成品的決定。用戶不必提供色碼或填表；估計字體／色值標估計。確認隨完整計劃保存，模式不能跳過確認。

每張生成重新帶真素材及適用參考，不能只靠文字 Style 或上一張生成圖。
