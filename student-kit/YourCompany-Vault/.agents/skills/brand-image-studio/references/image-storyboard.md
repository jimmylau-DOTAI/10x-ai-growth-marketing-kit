# 每張一項任務，集中記錄

在一份 `creative-plan.md` 維護共用 Style／品牌規則，以及每張製作卡；已有 blueprint／creative-plan 文件沿用，不搬格式或重複內容。

每張只記：
1. 圖號、用途／頁次、版本、比例／尺寸及語言。
2. 一個主要購買問題／主張、來源及限制。
3. 全部實際圖內文案；配套 caption 等另列，不送進圖內。
4. 主體、構圖、閱讀順序、必要動作及沿用 Style。
5. 真原素材、Logo、適用參考的路徑與各自角色。
6. 已確認範圍、實際輸出路徑、檢查及客戶意見。

產品只帶本張涉及的外觀／操作限制；服務只帶本張涉及的範圍／流程／交付限制。共同規則引用一次，不每頁抄整套。

每次工具只接收該卡的文案、構圖、相關原素材、參考及必要限制。明確只生成一張完整成品，不送整套藍圖／其他頁文案。單頁的步驟或比較模組可以保留，不能把多張交付縮成一張總覽。

客戶先看方向、各圖目的／畫面與完整對外文案，內部路徑／編碼毋須逐項審。按主指引確認後才生成；批量不逐張等，先試一張才停在代表圖。
