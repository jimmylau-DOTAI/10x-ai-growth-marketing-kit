# 看參考，再提取可用結構

真看用戶指定圖片；指定「呢張」就以它為主。多張同系列可按頁面用途取相應參考，風格衝突先釐清。長頁／mood board 看不清才裁局部，生圖帶當頁適用的清楚原參考。

在現有計劃記：
- 主參考及輔助參考各負責甚麼。
- 版面骨架與主體位置／大小。
- 明暗、色彩角色、材質與光線。
- 字級、文字密度、圖文比例與閱讀順序。
- 分隔／裝飾特徵，以及不可搬入的身份與主張。

用可見特徵描述，不只寫「高級、好睇」。產品／服務事實及我方文案決定內容，參考不提供功效證據。

生成後縮圖並排，比較明暗、主要色塊、主體比例及圖文密度。明顯偏離已選風格就指出並修正具體偏差，不另創方向。修改不得重畫真產品、真 Logo 或帶入對方案例。

不用另外生成純 mood image 作證明；代表圖必須是已要求成品中的一張。
