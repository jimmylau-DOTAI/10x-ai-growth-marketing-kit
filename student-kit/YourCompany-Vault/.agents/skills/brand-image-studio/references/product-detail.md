# 詳情圖：按買家問題排頁

只在產品詳情、服務介紹或多屏 offer 任務讀此檔；單張廣告走 image-plan。

每頁圍繞一個主要購買問題。按交付張數、重要性及證據，採用／合併／省略以下內容：

| 產品可選內容 | 服務可選內容 |
| --- | --- |
| 產品辨認、款式／適合誰 | 服務定位、適合誰 |
| 功能及有依據的選購理由 | 客戶問題、方法及合理預期 |
| 材質／成分、實物細節 | 具體服務內容、真實資歷 |
| 準備／使用／安裝 | 參與／預約／交付流程 |
| 規格、版本、適配 | 方案、交付物、時間／條件 |
| 買前限制、FAQ、CTA | 範圍限制、FAQ、CTA |

不預設每項一張，也不要求全部出現。混合 offer 按買家讀序結合，標清產品與服務各自承諾。張數不足先提出重點取捨；不自行加頁。

產品畫面用真相及已核實動作，場景光線、透視與接觸陰影要一致；缺角度就換構圖。服務可用流程、交付樣本、真實人物或明確示意；不仿造 dashboard、案例或證書。

完整文案與製作卡按 [pdp-blueprint.md](pdp-blueprint.md)。參考提供讀序與呈現方式，不提供產品機理或服務成果證據。
