# 單張圖片計劃

先沿用任務與已確認理解。單張廣告／海報只準備一個主要主張，不先展開詳情頁或三方向比較。

在現有計劃寫：買家問題、來源支持的回答、全部圖內文字、主要畫面與閱讀次序、比例／尺寸、原素材／Logo／參考、限制。欄位需要時按 [image-storyboard.md](image-storyboard.md)，不重複另填表。

- 廣告：一個主張、必要說明及合適 CTA；配套 caption／廣告文案按用戶要求。
- 商品主圖／細節：清楚辨認產品或展示有證據的局部，無字亦可；不虛構結構。
- 服務／活動：呈現問題、方法或交付；不捏造講師、場地、案例或效果。
- 既有圖修改：沿用原計劃，只處理指定 Logo、文字或構圖變更。

構圖需要深化時才讀 [design-brief.md](design-brief.md)。先展示完整對外文案與畫面方向並確認，再按 native-images 製作。內部 TBC 留在製作備註；買家需要知道的真實限制則清楚保留。工具限制不能靠拉伸產品或縮字掩蓋。
